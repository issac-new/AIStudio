# 认知格栅（Cognition Lattice）

综合认知知识库，覆盖人类认知偏差、心理效应、思维模型、思维框架、跨学科心智工具、东方传统智慧、论证谬误、管理思维及成长思维模型九大维度，总计1969条标准化知识条目。灵感源自查理·芒格「多元思维模型格栅」（Latticework of Mental Models），融合东方传统智慧与西方逻辑学体系，旨在为Agent提供最全面的认知科学与批判性思维知识体系。

## 标准条目格式

每个知识条目包含以下标准化字段：

```
### 序号. 中文术语 (English Term)
- **释义**：一句话定义
- **核心机制**：工作原理/心理机制说明
- （分类特定字段）：如来源学科、创始人、典型步骤等
- **典型应用场景**：场景1、场景2、场景3
- **相关概念**：相关条目1、相关条目2、相关条目3
```

部分条目额外包含：
- **精辟释义**：更精炼的一句话核心释义（针对认知偏差和心理效应）
- **来源流派**：所属东方传统流派（针对东方智慧）
- **典型示例**：具体示例（针对论证谬误）
- **识别方法**：如何发现谬误（针对论证谬误）

### 如何使用本Skill

1. **先读取本SKILL.md获取索引**，确定知识所在维度
2. **Orchestrator 专用**：先读取 `references/orchestrator_integration.md`，它将1969条知识映射到 orchestrator 的核心决策场景（任务拆解/看板路由/Worker分配/优先级/风险评估/跨看板协调/偏差自检）
3. **按需读取references/下的对应文件**，获取详细条目
4. **引用时遵循标准条目格式**，确保释义和机制准确
5. **典型应用场景字段**可帮助将概念映射到具体场景
6. **相关概念字段**可构建知识网络，深化分析

### 检索策略

- **按术语检索**：直接搜索中英文术语名
- **按场景检索**：搜索"典型应用场景"中的关键词
- **按分类检索**：浏览分类体系定位相关概念
- **按关联检索**：通过"相关概念"字段扩展知识网络
- **跨维度检索**：偏差→效应→模型→框架→工具→智慧→谬误→管理→成长，九维度联动

### 注意事项

- 本知识库为静态参考库，无需外部工具调用
- 部分概念在多个维度中交叉出现（如"确认偏误"既是认知偏差也是思维模型要素），引用时选择最相关的维度
- "典型应用场景"是概括性示例，实际应用可能更广泛
- 引用时应根据上下文精简释义，避免全文照搬
