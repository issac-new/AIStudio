## 0. 为什么需要这个情景库

2026-09-15 Clarity Act 在参议院程序性投票折戟（50-49，需 60 票）[E1: paymentsdive.com/news/clarity-act-fails-senate-trump-crypto-conflict-of-interest-sec-cftc/830651/]，美国加密市场结构立法进入空窗期，监管蓝图改由 SEC/CFTC 自行铺设。对跨境清算系统的含义：**不能再押注单一联邦立法路径**——合规依据正在向「立法空窗 + 州级牌照 + 监管规则」多分支演化。本库把三条分支路径的事实基线、触发信号与清算影响固化为可复查结构，供跨境方案评审引用（gap 验证口径：下次跨境方案评审文档实际引用本库 ≥1 处）。

外部参照系：欧盟 MiCA（已生效，ESCB 正推动修订存款配额）与香港《稳定币条例》（已生效并发出首批牌照）构成非美法域对照，用于校准三路径的极端取值。

## 1. 监管分支情景库（pay-fintech 半区）

### 1.1 三路径定义卡

#### P1 立法失败路径（当前实际状态：已发生）

**定义**：Clarity 类市场结构立法持续搁浅，稳定币监管长期停留在 GENIUS Act 单法格局 + 执法个案填补，联邦层面无统一市场结构规则。

**监管事实基线**（截至 2026-09-24）：
- GENIUS Act（Public Law 119-27，2025-07-18 签署）为现行唯一联邦支付稳定币法 [E3: §C.2]：OCC 联邦合格发行人；发行规模 ≤100 亿美元可选州级（须"实质相似"）；储备 ≥1:1 限美元现金/美联储存款/93 天内国库券/隔夜回购/注册货基，禁再质押，月度披露+会计师审验，CEO/CFO 月度认证（虚假认证负刑责）；BSA 反洗钱义务；须具备依法冻结/扣押/销毁的技术能力；主要条款 2027-01-18 或实施细则出台后 120 天生效（取早者）。
- **GENIUS 三家实施细则已齐（2026-09-24，"三监管三路径"，细节见 §1.4）**：OCC（2026-02-25，12 CFR Part 15 提案）、FDIC（2026-04-10，12 CFR Part 350 提案）、Fed（2026-09-24，Reg UU/12 CFR 247 提案）——三家均提案期内，无最终规则 [E1]。
- Clarity Act 程序性否决 50-49（2026-09-15，需 60 票），Tillis 重新提交动议；争议焦点=稳定币收益/利息条款 + 特朗普家族加密利益回避 [E1: Payments Dive 830651]。
- 立法空窗期的直接后果：收益/利息条款、二级市场/DeFi 交互的联邦规则缺失，靠 SEC/CFTC 执法个案与指南填补 [E1: 同上]。

**触发信号**（可观察、可核验）：
- 转强信号：Clarity 动议再投票仍 <60 票；国会换届年前无新市场结构法案排期；SEC/CFTC 以执法代替规则的案例累积。
- 转弱信号：收益条款妥协案过关委员会；两党重启 market-structure 谈判并公布文本。

**合规规则包影响**（对应 gap-20260919-002 可切换规则包；默认取值倾向）：
- 储备规则包：取 GENIUS 基线（1:1 + 月度审验），无增量。
- 赎回规则包：取 GENIUS"公开及时赎回政策"弱 SLA（无硬性时限），费用变更提前 7 天披露。
- 跨境通道门槛规则包：**保守取值**——仅走已持牌发行人走廊，通道门槛按 BSA/OFAC 现行执行；收益条款置空（不配置）。
- 收益/利息条款：**未定义**（Clarity 折戟的争议核心即在此）[E1]。

**证据强度**：路径本身=E1（投票结果事实）；规则包取值=E4（推断）。

#### P2 州级牌照路径（当前实际状态：进行中，加速）

**定义**：发行人以州级牌照 + OCC 国民信托牌照为主要准入路线，形成 50 州拼图 + 联邦信托双轨；GENIUS 州级选项（≤100 亿美元、"实质相似"）为法域依据。

**监管事实基线**（截至 2026-09-24）：
- OCC 国民信托牌照潮 [E3: §C.2 后段]：2025-12 起 5 家有条件批准；2026-08 OCC 代理货币监理长 Gould 讲话披露 de novo 申请 40 份、其中 23 份涉数字资产；Circle 2026-07 获正式批准；Revolut 2026-09-03 获有条件批准设立美国国民银行（全球客户 8000 万+，可直接经营 FDIC 保险存款、贷款、信用卡及稳定币）[E1/E2: OCC 公开讲话与 Payments Dive/PYMNTS 报道，经 radar 2026-09-24 收录]。
- 州级侧：GENIUS 州级选项要求与联邦"实质相似"，但披露频率/储备构成细节由各州自定 [E3: §C.2]；NYDFS 信托等既有州框架继续运行。
- 香港对照（域外管辖先例）：《稳定币条例》2025-08-01 生效，实缴股本 ≥2500 万港元、储备 100% 高质素资产隔离托管+每日披露、1 个工作日内按面值 1:1 赎回、无牌发行最高罚 500 万港元+7 年监禁；截至 2025-09-30 收 36 份申请，首批牌照 2026-04-10 发出（汇丰、碇点金融 Anchorpoint）[E3: §C.2；来源 HKMA 新闻稿 2025-07-29]。

**触发信号**：
- 转强信号：OCC 批准节奏加快（观察 23 份数字资产申请的批准率）；更多州落地"实质相似"细则；Revolut 类跨境数字银行以国民银行牌照绕开代理行直连美元体系 [E2: radar 2026-09-24 Revolut/Nubank 信号]。
- 转弱信号：联邦优先（preemption）条款随新法案推进；OCC 收紧 de novo 审查。

**合规规则包影响**：
- 储备规则包：多法域变体并存（GENIUS 基线 + 州变体 + HKMA 每日披露标准），规则包须按"发牌法域"维度参数化。
- 赎回规则包：HK 硬 SLA（1 个工作日）与 GENIUS 弱 SLA 并存，取发行人牌照法域对应值。
- 跨境通道门槛规则包：碎片化——州/联邦/HK 三层门槛矩阵，维护成本最高。
- 收益/利息条款：按州各别（如 NYDFS 框架下有限允许），联邦层面未定义。

**证据强度**：OCC 牌照事实=E1/E2；规则包取值=E4。

#### P3 监管蓝图路径（当前实际状态：草案期，SEC/CFTC 已表态）

**定义**：SEC/CFTC 以规则制定（rulemaking）自建市场结构与稳定币监管蓝图，Clarity 型条款被拆散在机构规则中逐块落地。

**监管事实基线**（截至 2026-09-24）：
- Clarity 折戟后 SEC/CFTC 公开表态将自行铺路 [E1: Payments Dive 830651]——具体规则文本**尚未发布**，状态=草案期前（机构路线图阶段）。
- 欧盟平行参照（蓝图路径的已落地样本）：MiCA（EU 2023/1114）稳定币条款 2024-06-30 起适用、全面适用 2024-12-30；EMT/ART 分类管理；100% 储备含存款；法定赎回权 [E3: §C.2]。
- ESCB 2026-09-22 响应欧盟委员会 MiCA 定向咨询：**建议**（非现行法）废除 30%/60% 银行存款配额，改 1 日/5 日流动性桶（非重要 20%/30%、重要 40%/60%），理由=存款配额造成银行↔稳定币双向传染；MiCA Art.54/58 现行条款仍有效，修订需走欧盟立法程序 [E1: Reuters 2026-09-22 reuters.com/business/finance/ecb-eu-central-banks-oppose-stablecoin-bank-deposit-rule-2026-09-22/；ESCB 咨询回应全文 PDF（ECB 官方一手，实测 200，2026-09-24）ecb.europa.eu/press/consultationresponse/pdf/ecb.conresp202609_micarreview.en.pdf；E2: CryptoSlate 对比表]。同期英国央行系统性稳定币 Code of Practice 咨询截止，排除商业银行存款背书路线 [E2: FintechWeekly]。

**触发信号**：
- 转强信号：SEC/CFTC 发布稳定币相关概念释放/托管规则草案；欧盟采纳 ESCB 流动性桶方案进入立法程序；英国 Code of Practice 定稿。
- 转弱信号：国会重新接管（Clarity 复活或替代法案通过），机构规则让位。

**合规规则包影响**：
- 储备规则包：机构规则可能**超出** GENIUS 基线（参照 ESCB 流动性桶思路，从"资产构成"转向"期限桶"管理）——预留期限桶参数位。
- 赎回规则包：趋向硬 SLA（HK 的 1 个工作日、MiCA 法定赎回权为锚）。
- 跨境通道门槛规则包：以 BSA/OFAC/旅行规则（FATF）为中心的联邦统一门槛，替代州拼图。
- 收益/利息条款：欧盟蓝图样本已定——ESCB 明确主张**维持禁止稳定币付息**，并把绕道形态（tri-party 方案、借贷/质押生息）一并纳入禁止范围（官方文本 ¶31-33）[E1 ECB conresp202609]；美国侧已从推断升级为提案级证据：OCC Part 15 提案将付息禁令扩展至"关联方/第三方代付收益"并设可反驳推定（2026-02-25）[E1: occ.gov nr-occ-2026-9；E2: JD Supra/Manatt 2026-02 复核]，Clarity 条款层面的立法悬置未解但监管取向已明。

**证据强度**：SEC/CFTC 表态=E1；规则取值=E4（草案期，禁止硬编码任何未生效条款——gap-20260919-002 核心约束）。

## 2. 跨境清算影响矩阵（pay-clearing 半区）

### 2.1 矩阵主体（三路径 × 七维度）

清算机理基线 [E3: ZF002_第2章；国际视角知识文档 §A.3/§A.4]：代理行/清算行/CIPS 三模式；SWIFT=信息通道≠资金通道；CHIPS 处理 95% 全球跨国美元大额清算（2024 年日均结算约 1.85 万亿美元/56.5 万笔，流动性效率 29:1）；Fedwire RTGS 即时不可撤销；Herstatt 风险由 CLS PvP 消除（2024 年日均 7.2 万亿美元）；稳定币轨 7×24 秒级、成本 0.1%-0.5% vs 传统汇款 >6%，流通约 2690 亿美元（S&P 预测 2028 达 4340 亿美元）、99% 锚美元，采用集中于阿根廷/尼日利亚等汇款刚需市场，消费电商占比约 0.2% [E2: Moody's 2026-05-13 / S&P Global 2026-05-11，经 Payments Dive 2026-05-19 转述——KC-015：引用须带此口径+窗口]。

| 维度 \ 路径 | P1 立法失败 | P2 州级牌照 | P3 监管蓝图 |
|---|---|---|---|
| **① 结算时效与可用性** | 稳定币轨 7×24 秒级优势保留，但仅限持牌走廊；美元终局结算仍依赖 CHIPS/Fedwire 营业时段窗口 [E3 §A.3/§A.4]。严重度 **M**（E4） | 同 P1 基础上，跨州走廊可用性受各州细则差异影响，节假日/截止时间矩阵碎片化。严重度 **M**（E4） | 机构规则可能统一结算窗口标准（参照 MiCA 全面适用节奏），7×24 轨与 RTGS 轨的衔接规则有望成文。严重度 **L→M**（E4） |
| **② 清算拓扑** | 代理行链（发端行→美元代理行→CHIPS/Fedwire→收端代理行）与稳定币直连轨（issuer→链→redeemer）并存双轨 [E3 ZF002]。严重度 **H**（E4；双轨并存=拓扑复杂度峰值） | Revolut 类国民银行牌照使跨境资金绕开代理行直连美元银行体系，Nostro 层级压缩 [E2 radar 2026-09-24]。严重度 **H**（E4） | 蓝图若成文，拓扑收敛为"传统 RTGS + 合规稳定币轨"可互操标准（多轨路由参照 Pontes 上线后的欧盟双轨经验 [E1 radar 2026-09-24：ECB 2026-09-21 上线，13 银行+4 DLT 运营商，2028 全面投产]）。严重度 **M**（E4） |
| **③ 币种与汇兑路径** | 99% 锚美元 → 美元结算地位被动强化，汇兑点前移至 on/off-ramp [E3 §A.4；E2 KC-015 口径]。严重度 **M**（E4） | 多法域发牌（含 HK 域外管辖）催生合规多币种稳定币（港元锚先例），汇兑路径分叉增多。严重度 **M**（E4） | 机构规则若按存款类管付息币种，非美元锚合规发行空间打开（MiCA EMT 先例）。严重度 **L**（E4） |
| **④ 备付金与流动性管理** | 发行人储备以 93 天内国库券为主 → 大额赎回冲击国库券市场，跨境在途头寸暴露于脱锚瞬断（ESCB 指出的双向传染机制 [E1 2026-09-22]）。严重度 **H**（E4，锚定 E1 机制） | 州拼图下储备构成差异大，流动性质量分层，跨境对手方尽调成本上升。严重度 **H**（E4） | ESCB 流动性桶方案（1 日/5 日桶，非重要 20%/30%、重要 40%/60%）若落地，储备管理从"资产清单"转向"期限桶"——备付金模型需参数化重构 [E1；**建议非现行法**]。严重度 **M**（E4） |
| **⑤ 对账与差错处理** | 链上终局 vs 3 对账周期错配：链上秒级终局后传统在途/对账窗口仍在跑，差错处理须支持"链上已终局、账务在途"中间态 [E3 kernel：清算≠结算、4 环节 3 对账 3 在途]。严重度 **H**（E4） | 多发行人多链并存 → 对账维度爆炸（发行人×链×法域），差错归因链变长。严重度 **H**（E4） | 统一规则若含链上结算法律终局性条款，对账基准日/基准时点有法可依。严重度 **M**（E4） |
| **⑥ 合规校验点** | 规则包三件套（储备/赎回/跨境门槛）按 GENIUS 基线取保守值，通道校验=BSA/OFAC 现行 [E3 §C.2]。严重度 **M**（E4） | 三层门槛矩阵（州/联邦/HK）实时校验，规则包须按发牌法域动态路由 [E3 §C.2]。严重度 **H**（E4） | 校验点联邦统一化，规则包从"矩阵"回退为"单参"，但新增期限桶/收益类校验位 [E1 ESCB 方向，草案]。严重度 **M**（E4） |
| **⑦ 系统改造成本与切换用时** | 双轨并存=适配层全量设计但只启用保守规则包，改造成本最低、切换最快。严重度 **L**（E4） | 多法域规则包矩阵+动态路由=改造成本最高；切换用时按"新州细则落地→规则包上线"人月计。严重度 **H**（E4） | 单一联邦框架若成文，长期成本最低，但迁移期（规则发布→生效）双套并行成本峰值。严重度 **M**（E4） |

### 2.2 可插拔稳定币结算适配层设计约束（对接 gap-20260921-013）

**定位**：清算网关内侧的结算轨道适配器（design-only，不生产化）。

1. **接口边界**：适配层对外暴露统一结算接口（发起/查询/退回/对账四原语），对内封装稳定币轨 specifics（链、发行人、赎回机制）。清算内核不感知链细节——遵循"清算≠结算"内核分层 [E3 kernel]。
2. **三类规则包切换口**（gap-20260919-002 可切换规则包落位点）：
   - 储备校验口：输入=发行人+法域 → 输出=储备构成/披露频率校验参数（P1 基线 / P2 矩阵 / P3 期限桶预留位）。
   - 赎回 SLA 口：输入=牌照法域 → 输出=SLA 时限与费用变更通知期。
   - 跨境通道门槛口：输入=走廊（币种×法域对）→ 输出=门槛阈值组（州/联邦/HK 三层）。
   - 约束：所有规则包**只装已生效条款**；未生效条款（Clarity、ESCB 方案、SEC/CFTC 草案）只建参数占位，不预写取值。
3. **双轨切换演练**（gap-20260922-014 验证动作）：每年至少 1 次桌面推演，剧本固定为"Clarity Act 失败情景"（即 P1→P2 漂移）：检验规则包切换耗时、在途头寸处置、对账中间态闭环；另加 1 次赎回挤兑冲击演练（剧本=脱锚→大额赎回→储备资产抛售传导）。
4. **不生产化约束**：监管未定（P3 草案期前）期间，适配层仅存在于设计文档+沙箱原型，禁止接入生产清算流；生产化前置条件=P3 规则成文或 P2 门槛矩阵稳定运行 2 个季度。

### 2.3 关键风险注记

1. **挤兑/脱锚对跨境清算的冲击**：发行人储备集中于短期国库券，挤兑时抛售→价格下压→进一步赎回的螺旋（ESCB 2026-09-22 咨询回应指出的双向传染机制 [E1]）；跨境清算侧的暴露点=在途头寸（链上已终局、法币腿未完成）与以稳定币计价的备付金。缓释=在途头寸限额+脱锚熔断（阈值入规则包占位）。
2. **监管套利**：州 vs 联邦 vs 域外管辖（HK 条例覆盖海外发行锚港元+向港公众推广 [E3 §C.2]）三层错位，发行人 forum-shopping 使走廊门槛形同虚设；跨境系统须按"发牌法域"而非"交易发生地"校验。
3. **链上终局性 vs 清算最终性**：链共识终局（技术终局）≠ 法律最终性（如 CHIPS 结算终局性、RTGS 不可撤销性的法定地位）；多数法域对链上结算的法律最终性无明确规定，结算风险被系统性低估——对账模块须显式区分两个时点 [E3 kernel + E4]。
