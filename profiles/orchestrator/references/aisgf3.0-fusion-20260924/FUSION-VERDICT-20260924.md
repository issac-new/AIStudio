## 二、语境过滤声明

本集群语境: batch=1 单人多域自建 agent 组织（Hermes 多 profile + kanban 派工 + Matrix 协作），无线上公众服务流量、无算力基础设施、无具身智能硬件、不受行业监管备案约束。

**整类 DROP（依附语境不存在，写明防重复提议）**:

| 源机制 | 语境 | 不吸收理由 |
|---|---|---|
| 4.3 沙箱监管制度（行业分类/责任豁免/数据共享平台） | 面向监管者对企业准入 | 我们不是监管机构；本集群的"沙箱"等效物已存在（Docker 隔离 + worktree + scope-gate） |
| 4.5.3 / 附件3-8 国际协同共治（联合国/APEC/全球南方） | 国家间治理 | 单机集群无此主体 |
| 2.3 衍生风险（就业结构/绿色低碳/文化多样性/智能鸿沟） | 社会宏观面 | 非单机 agent 组织可操作对象 |
| 2.2.2 具身智能风险（传感器干扰/物理执行/群体协同） | 机器人硬件 | 无具身智能资产 |

| 4.2.2 重要行业规范应用（政务/金融/广电行业指南） | 行业监管落地 | 无行业属性 |
