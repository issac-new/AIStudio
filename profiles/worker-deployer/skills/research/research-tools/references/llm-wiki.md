# LLM Wiki — Knowledge Base

Build and query interlinked markdown knowledge bases from Karpathy's LLM Wiki.

```bash
# Build the wiki from source
llm-wiki build

# Query
llm-wiki search "transformer architecture"
llm-wiki search "attention mechanism"
```

The wiki is a local markdown knowledge base with interlinked pages covering LLM concepts, architectures, training, and deployment.
