# arXiv Paper Search

Search arXiv papers by keyword, author, category, or ID.

```bash
arxiv search "transformer attention"
arxiv search --author "Karpathy" --max 5
arxiv search --cat cs.LG --max 10  # Machine Learning category
arxiv search --id 2301.12345
```

Categories: cs.LG (ML), cs.CL (NLP), cs.CV (vision), cs.AI (AI), stat.ML, math, physics, etc.
