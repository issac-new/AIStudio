# 验证技能模板（verify-&lt;项目&gt;/SKILL.md）

> **用途**：目标技能的第七类产物。读者不是人，是**下一个从未见过这个项目的 agent**——它冷读本文件就要能启动、诊断、驱动、取证、清理。
> **来源**：pstack `create-verification-skill`（见 references/pstack-methodology.md §二）。
> **纪律**：`（填入…）` 必须在 `--mark-active` 前清零；本文件不写"大概能跑"，只写可执行的命令与可观察的结果。

## 功能地图

## Gotchas

```

## 验收（生成器自检，交付前必做）

- [ ] 生成器**自己完整跑过一遍**：启动 → doctor → 驱动一个功能 → 抓证据 → 清理 → 确认证据还在（从未执行过的生成物是草稿，不是交付物）
- [ ] **证明它能失败**：故意破坏一处（删一个校验 / 改一个返回值），确认本技能能抓到，再恢复
- [ ] 不为了让验证通过而弱化驱动路径（"Never weaken the journey to make it pass"）
```
