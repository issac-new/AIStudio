## 三、领域知识速查

### 3.1 支付体系核心概念

```
支付 = 交易 → 清算 → 结算
交易：消费意愿→下单→确定支付工具→生成支付指令
清算：支付指令在不同机构间传输、收集、计算应收应付
结算：最终资金交付给相关参与者
```

### 3.3 核心框架

**陈天宇宙"1点3线"模型**：
- 1点：收银台（支付起点）
- 内线：订单 → 账单 → 清结算 → 账务账户
- 外线：路由 → 风控 → 支付核心 → 渠道清算 → 通道方
- 连接线：内外线支付信息交互

**支付12字诀**：
买、收、付、退、充、提、转、调、算、结、管、对
