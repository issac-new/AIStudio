## 一、原著考证

- 作者：钱学森（H.S. Tsien）。英文版 *Engineering Cybernetics*，McGraw-Hill，1954（首部系统讲述工程控制论的著作；中科院 1956 年一等科学奖）。中译本 1958 科学出版社；修订版与宋健合著（新增最速控制、分布参数系统、逻辑控制与有限自动机、信号与信息、大系统理论五章）。
- 章节主线（1954 版）：绪论 → 拉普拉斯变换法 → 输入/输出/传递函数 → 反馈伺服系统 → 稳定性（频率判据）→ 噪声过滤 → 采样（离散）系统 → 继电器/最速开关控制 → 多变量解耦（自治性）→ 自寻最佳点 → 自行镇定与适应环境的系统 → 误差的控制 → 可靠性设计（超稳定性）。
- 核心论断（多源交叉验证）：
  1. **反馈系统比开环系统更强健**——反馈可有效应对系统中各种不确定性因素或内外干扰（郭雷院士《系统的反馈原理及魅力》）。
  2. **稳定性的频率判据比代数判据更接近实用**——工具选择以工程实用性为准，不以数学优美为准。
  3. **用不可靠的元件组成可靠的系统**——大脑每天成千上万神经元死亡仍可靠工作；可靠性来自系统设计（冗余+反馈+协同），不来自元件可靠。容错计算与可靠性工程的理论源头之一。
  4. **技术科学方法论**——一般性理论与实际工程经验结合；被评价为"研究工程控制过程的方法论和认识论的一次系统尝试"。

来源：[维基百科·工程控制论](https://zh.wikipedia.org/zh-hans/工程控制论)、[科学网·解决老问题的新方法](https://news.sciencenet.cn/sbhtmlnews/2009/7/221603.html)、[科学出版社·钱学森与《工程控制论》](https://www.cspm.com.cn/zt2017/2014nzt/sqlj/201808/t20180801_263642.html)、[中国工程院·钱学森与控制论](https://www.engineering.org.cn/sscae/CN/1160103700859511735)、[中国科学院文献情报中心](https://yswk.csdl.ac.cn/arc_detail?bh=1957A03YX020012)、[Google Books 原版目录](https://books.google.com/books?id=QZ48AAAAIAAJ)、[百度百科](https://baike.baidu.com/item/工程控制论/8782823)。
