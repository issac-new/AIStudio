# /release-plan — 发布前质量检查

> **对应文章命令**：`/rd:release-plan`（原文"生成发布计划，发布待确认点"）
> **触发**：ops-devops 接到发布任务时
> **作用**：fail-fast——能在发布前暴露的问题，不拖到生产

---

## 一、触发场景

当 ops-devops 收到以下输入时，**必须先跑 release-plan**：
- 新功能发布
- 配置变更发布
- 基础设施变更
- 紧急修复发布

**不触发**：纯代码 review / 不需要发布的任务。

---

## 二、工作流

### 2.1 检查清单（8 项，全部机械可验证）

| # | 检查项 | 判定标准 | 结果标记 |
|---|---|---|---|
| 1 | 变更是否可逆？ | 有明确的回滚路径 | ✅/❌/N/A |
| 2 | 影响面评估？ | 明确 blast radius（多少服务/用户受影响） | ✅/❌/N/A |
| 3 | 监控确认？ | 变更后监控指标正常或已有告警规则覆盖 | ✅/❌/N/A |
| 4 | 灰度计划？ | 有明确的灰度/金丝雀发布计划 | ✅/❌/N/A |
| 5 | 回滚预案？ | 有明确的回滚步骤和触发条件 | ✅/❌/N/A |
| 6 | 观测点确认？ | 发布后有明确的观测指标 | ✅/❌/N/A |
| 7 | 文档更新？ | runbook / playbook 已同步更新 | ✅/❌/N/A |
| 8 | 审批记录？ | 高不可逆操作有审批记录 | ✅/❌/N/A |

### 2.2 可逆性分级（基于 `_shared/action-risk.md`）

| 级别 | 含义 | 处理方式 |
|---|---|---|
| **容易** | 可完全回滚，无副作用 | 直接执行 |
| **可逆** | 可回滚，但有副作用 | 需审批 + 回滚预案 |
| **不可逆** | 无法回滚或回滚成本极高 | 需 `kanban_block(kind="needs_input")` |

### 2.3 输出

生成 `release-plan.md` 报告：

```markdown
# release-plan 报告 — <任务标题>

## 检查结果汇总

| 检查项 | 结果 | 详情 |
|---|---|---|
| 1. 可逆性 | ✅ / ❌ | <具体说明> |
| 2. 影响面 | ✅ / ❌ | <具体说明> |
| 3. 监控 | ✅ / ❌ | <具体说明> |
| 4. 灰度计划 | ✅ / ❌ | <具体说明> |
| 5. 回滚预案 | ✅ / ❌ | <具体说明> |
| 6. 观测点 | ✅ / ❌ | <具体说明> |
| 7. 文档更新 | ✅ / ❌ | <具体说明> |
| 8. 审批记录 | ✅ / ❌ | <具体说明> |

## 可逆性分级

- **级别**：容易 / 可逆 / 不可逆
- **理由**：<具体说明>

## 发布计划

1. **灰度阶段**：<灰度比例 / 时间 / 观测指标>
2. **全量阶段**：<全量时间 / 观测指标>
3. **回滚触发条件**：<什么情况下触发回滚>
4. **回滚步骤**：<具体回滚命令/操作>

## 阻塞项汇总

<列出所有 ❌ 的项目及原因>

## 建议

<如果发布计划不合格，给出具体修改建议；如果合格，建议执行发布>
```

## 三、本 profile 视角适配（ops-devops 专属）

> **为什么散落到 ops-devops**：release-plan 是发布前的质量门，ops 是发布主力，由它负责发布入口质量最合理。

### ops 特有的判定标准

- **监控指标是否已配置**（Prometheus / Grafana / 日志告警）
- **灰度比例是否合理**（5% / 25% / 50% / 100%）
- **回滚时间窗口**（< 5 分钟 / < 30 分钟 / < 1 小时）

### ops 的工作流差异

```
1. 收到发布任务
2. 跑本 skill 的 8 项检查 + 可逆性分级
3. 输出 release-plan 报告
4. 报告写入 kb 后 → 执行发布 → 监控观测
```

## 四、验证清单（自检）

跑完 release-plan 后自检：

- [ ] 8 项检查全部跑了（非抽样）
- [ ] 可逆性分级明确（容易/可逆/不可逆）
- [ ] 每项有明确的 ✅/❌/N/A 标记（非"差不多"）
- [ ] 阻塞项已列出具体原因（非"有问题"模糊说法）
- [ ] 发布计划完整（灰度/全量/回滚/观测）
- [ ] 报告已写入 `_shared/knowledge/candidate/`（如适用）
