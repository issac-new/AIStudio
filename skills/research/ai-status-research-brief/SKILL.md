# AI 现状/趋势跨面调研报告（ai-status-research-brief）

> 从 2026-09-04《人工智能发展现状报告》会话提炼。范例产出：
> `research/ai-status-report-2026-09/`（三子报告+数据+终稿）。
> 上游工作流（派发/回收/恢复）见 `research-subagent-orchestration`；
> 本 skill 管跨面报告的内容结构、通道选型与验收。

## 三面结构与任务边界

| 面 | 覆盖 | 硬验收 |
|---|---|---|
| 学术面 | arXiv 目标分类窗口内全量分层抽样 ≥10%（90 天 cs.AI 实测 2100/14349）+ ≥8 组主题定向检索 | 主题分布表 + 15-20 篇代表作全解 + 局限声明（哪些月份覆盖薄） |
| 舆论面 | 主流公众号 5+ 个，目标 ≥40 篇全文（实测 559 篇） | 词频统计 + 热点 Top10（频次+跨源交叉）+ 不可达渠道如实列明 |
| 产业面 | ≥15 独立来源带 URL+日期 | 关键结论双源交叉；单源标【存疑】；口径差异单列 |

 Orchestrator 另自采一线硬数据（如 totalResults 月度曲线）做交叉验证基线 ——
 失败轮次的占位数据立即删除，防伪证据链污染。

## 数据通道速查

- **arXiv**：Atom API + `opensearch:totalResults` 探总量（不翻页）；批量统计间隔 ≥10s（实测 3s 间隔 12+ 查询触发 500/429 长限流）；查询串 quote_plus 全编码。详见 `arxiv` skill。
- **微信公众号**：官方站/镜像优先——量子位 wp-json（545 篇全文零验证码）、虎嗅镜像（夕小瑶全文）、今天看啥（新智元仅标题流）、机器之心（仅索引，正文 JS 锁）→ 搜狗兜底且实测第 4 个账号即封。死路勿试：36氪/InfoQ/CSDN Datawhale/PaperWeekly.info/智源社区。产出按 fulltext/ + dataset/corpus_index.json + raw/ 三目录分离并机械对账。详见 `sogou-wechat-batch-fetch` skill。
- **产业面**：web_search+web_extract，优先官方一手页与政府文件；每数字带 [S#] 锚点回溯来源附录。

## 合并验收（Cross-face reconciliation）

1. **共振表**：≥2 面互证的结论 → 高置信，逐面证据并排。
2. **背离表**：单面结论或冲突口径 → 显式标注【存疑】/按谣言处理/口径差异，禁止静默调和（如"半年投资 $510B"=VC 口径 vs "$700B capex"=超大规模厂商口径，同名不同义不可合并）。
3. **机械对账**：交付前 grep 计数关键数字（终稿 vs 子报告一致）；抽查来源锚点真实性。
4. **结构**：Executive Summary 3 个决定性发现+趋势判断；各面结论引用子报告路径；局限与防幻觉纪律成节。

## Anti-hallucination 纪律

- 无来源数字零采信；公司口径数字标注「公司口径」。
- 舆论面独有信号（如"灰测/爆料"）未经产业面佐证按谣言处理，可作情绪指标不作事实引用。
- 榜单排名类数据标注采集日期（榜单日更，隔日即失真）。

## Pitfalls（实测教训）

- **占位数据毒化**：子代理/自采失败轮次的 `-1`/null 占位文件必须当场删除并在报告附录声明缺口，否则后续读者会当真实数据引用。
- **子代理自报要抽验**：子代理声称「已写入某文件/已落盘」需抽读文件核实后才可进入终稿引用链。
- **skill 批操作原子性**：同批次一个操作失败会回滚全部已成功操作——多个写操作拆成独立调用；新建 skill 后同会话内 patch/write_file 可能因注册表滞后而报 not found，此时用 create 全量重写作为变通。
