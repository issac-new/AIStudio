# Cybernetics Dual Lens（控制论双书透镜）

> **完整触发语义**: 设计/评审 watchdog、验收门、打回策略、派工制度、指标上线、fallback、复盘系统性事故时加载本速查表，用钱学森《工程控制论》+金观涛《控制论与科学方法论》21 主题透镜过一遍再落稿。
> 来源: 2026-09-07 两书全文级调研（钱书 → `workspace/research/engineering-cybernetics/`；金书 2025 万有引力版 → `workspace/research/cybernetics-methodology/`）。本 skill 是速查层；完整论证与原著页锚在两个 concept-extraction.md。

## 定位

- **钱书 = 工程数学层**：怎么造回路（能观测性/自寻优/采样/冗余的硬技术）。
- **金书 = 方法论哲学层**：为什么这样设计组织与认知（可能性空间/稳态/黑箱/智力放大）。
- 两书独立得出同一结论时（会师）置信度最高，优先引用。

## 21 主题速查表（触发场景 → 用哪条）

| 触发场景 | 主题 | 核心判据 |
|---|---|---|
| 设计监控/告警 | 金·半反馈 vs 完整负反馈 | 告警必须可积累（登记→跟踪→复测），否则是半反馈（保险丝模式） |
| 设计 watchdog | 金·超稳定系统 | 靠不稳定维持稳定；修复机制自身失效=静默失稳→交叉互检，勿无限叠层 |
| 验收标准写法 | 金·理论清晰性=信息量 | 每条验收须二分可答通过/不通过；"要完善"=0 信息量禁入 |
| 打回 worker | 金·反馈过度 | 打回必附方向+边界（改什么/不改什么），防两极端振荡 |
| 打回前判断 | 金·可判定条件 | 验收失败≠产出错误，先查判据/环境/可复现性 |
| 派工任务书 | 金·通道容量+信息衰减律 | 只放该任务需要的 context；附原文锚点不做二级转述 |
| 选 assignee | 金·智力放大 | 选人=小范围选择放大为方案选择；看该域验收通过率（M/m） |
| delegate 链路 | 金·共轭控制 | 派工=L，验收=L⁻¹；缺验收变换=链路不闭合（自述不可信） |
| 多源调研/Checker | 金·滤波六法 | 通道各环节尽量不同（曾参杀人）；同模型自审无效 |
| fallback 设计 | 金·远缘繁殖 / 钱·异构冗余 | 同构板凳防不了共因失效（两书会师） |
| 指标上线 | 金·滤波+钱·噪声过滤 | 先过滤再反馈：窗口/样本量/置信度声明（两书会师） |
| 观测周期 | 金·反馈速度律 / 钱·采样定理 | 观测须快于被控对象漂移（两书会师） |
| 盲区治理 | 金·可观察变量限制 / 钱·能观测性 | 先开变量再谈治理；不测量则循环无效（两书会师） |
| 失败复发分析 | 金·有记忆的控制 | 记忆=排除已证伪状态；失败不打标=无记忆随机控制 |
| 排除表维护 | 金·记忆陷阱 | 记忆会错误排除→failure-mode-playbook 需复核周期 |
| 验收范围 | 金·可能性空间 M/m | 控制到足够小的范围即成功；追求唯一实现路径=一个网眼捕鸟 |
| 事故爆发分析 | 金·自繁殖 | 查负反馈抑制机制是否被破坏；临界值思维做容量规划 |
| 组织演化 | 金·自组织五特征 | 组织核心决定形态（上梁不正下梁歪）；不可逆→早期质量门槛高 |
| prompt 设计 | 金·黑箱认识论 | worker=黑箱：只谈输入输出，禁内部状态诛心断言（不可证伪） |
| 预算估计 | 钱·摄动灵敏度 | 预估轮次=对复杂度估计误差的显式裕度 |
| 规则防博弈 | 钱·多指标约束 / 金·Goodhart | 单指标必被博弈，Pareto 多指标 |

## 不可迁移边界（防过度映射）

钱书: 传递函数/频域、HJB 求解、Lyapunov 精确证明、卡尔曼滤波直套。
金书: 突变理论数学（只用定性结论）、中医藏象模型、超稳定社会史论、信息量 bit 计量（用可判定性替代）。

## 使用规则

1. 设计类决策（新 watchdog/验收门/派工制度）落稿前，过一遍速查表相关行，finding 写入设计文档的「控制论自检」段。
2. 复盘类（同类失败 ≥2 次）先查「有记忆的控制」与「自繁殖」两行再归因。
3. 引用原著结论时回 concept-extraction.md 取页锚，不在本 skill 内造锚。
