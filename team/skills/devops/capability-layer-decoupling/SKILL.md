# 能力层-实例层解耦迁移（capability-layer-decoupling）

共享能力层文件（教学工具包/框架/知识索引/调度台工具卡/教师 rules）出现具体孩子锚定
（名字、档案 file:line、作息、兴趣、单家庭事件）时的迁移程序。架构不变量与多租户
边界见 default profile 的 `[已移除]-multitenant-family`（本 skill 只管迁移执行与验收）。

## 迁移顺序（判例先行，禁先删后建）

1. **全量摸底**：`grep -rn "<孩子名>\|child-profile\.md" <共享层目录>` 计数到文件级，
   逐条判性（违规锚定 or 豁免，见下表），形成迁移清单。
2. **实例先落位**：目标实例文件 `references/children/<id>/<topic>-application.md`
   逐条接收原判例，**file:line 锚点逐字保留**——迁移前后逐锚点对照，零丢失才动本体。
   实例文件缺失锚点的，先补齐再继续。
3. **本体通则化**：共享层句子改写为年龄带/孩子类型通则 + 实例指针
   （「实例见 children/<id>/<topic>-application.md :NNNN 锚」）。指针允许提及实例
   存放位置，不允许把孩子的行为/作息/兴趣写进共享正文。
4. **「某孩子专属」特判 → 类型化通则**：改写时补齐分支——「<类型>型孩子走本通则；
   非 <类型> 型走常规路由」。只迁特判不留分支，未来别的孩子命中同型时会漏路由。
5. **备份 + 终验**：改前 `cp <file> <file>.bak-<日期>`；改后 grep 复扫：孩子名计数 = 0、
   `child-profile\.md` 计数 = 0（豁免类除外）；行为层抽 3 处对照确认教学能力无损。

## 残留引用豁免分类（终验时逐条定性，非豁免即改）

| 豁免类 | 判据 |
|---|---|
| symlink 兼容层声明 | 说明硬路径兼容机制本身，非内容引用 |
| 多租户纪律自述 | 「回复不得含某孩子信息」这类隔离验收清单——孩子名是纪律的检查对象 |
| 隐私边界事实陈述 | 机器主人/维护者身份说明 |
| 分层纪律实例指针 | 「具体孩子的落地实例见 children/<id>/…」的机制指路 |
| 债务登记行 | 已登记待迁的显式欠账记录 |

违规锚定判据：把特定孩子的行为模式、作息、兴趣、事件写进共享正文的判断依据——
调度台/教师读共享层即可下结论时绕过了档案层。

## 尾巴收尾执行模式

完成汇报中声明的遗留小项（「下轮顺手转档」级），用户回「小尾巴也收尾」即**当轮
亲手清零**：单文件小改由 orchestrator 直改（备份→改→grep 终验→评论归档到原卡），
不重开卡不重派工——收尾成本低于重派成本。多项或跨文件才立卡。
