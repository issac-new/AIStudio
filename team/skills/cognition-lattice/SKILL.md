# 认知格栅（Cognition Lattice）

静态中文认知知识库，灵感来自查理·芒格的「多元思维模型格栅」：九个维度、77 个分类、1975 条条目，正文全部位于 `references/`。本技能只提供概念定义、机制、应用场景与关联概念，不联网、不修改业务代码。

## 使用流程

1. 在技能根目录执行 `scripts/lattice.py search <术语>`，得到条目 `ID`、`维度/分类`、`references/文件:行号`。
2. 执行 `scripts/lattice.py show <ID>` 读取该条完整正文。只读取命中条目，避免把 40–430 KB 的单个知识文件整体载入上下文。
3. 需要分类全貌、字段模板、来源与质量基线时，读取 `references/catalog.md`。
4. 引用时标注「术语 + `references/文件:行号`」，压缩「释义 + 核心机制 + 典型应用场景」后用自己的话表述，不照搬条目全文。
5. 结论依赖模板化批次条目时，补充常识校验或换用另一维度的同名条目（见「数据质量」）。

脚本仅依赖 Python 3 标准库：`python3 scripts/lattice.py <子命令>`。

| 目的 | 命令 |
|------|------|
| 查术语（支持中英文、别名） | `python3 scripts/lattice.py search 损失厌恶 --limit 10` |
| 多关键词（AND）与正文检索 | `python3 scripts/lattice.py search 系统 反馈 --full` |
| 限定维度并直接看正文 | `python3 scripts/lattice.py search 锚定 --file cognitive_biases.md --show` |
| 读单条正文 | `python3 scripts/lattice.py show MM-0001` |
| 按位置读正文 | `python3 scripts/lattice.py show <文件>:<行号>` |
| 比对同名条目 | `python3 scripts/lattice.py search 幸存者偏差` |
| 全库审计 | `python3 scripts/lattice.py audit` |
| 生成机读索引 | `python3 scripts/lattice.py index` |
| 无损清洗（幂等） | `python3 scripts/lattice.py fix` |

## 场景 → 维度组合

- **决策复盘**：认知偏差 + 思维模型（概率/决策类）+ 论证谬误（涉及论证时）。
- **论证与辩论审阅**：论证谬误 + 思维框架（批判性思维）+ 认知偏差；谬误识别工具清单与场景指南位于 `argumentation_fallacies.md` 尾部。
- **战略规划**：思维框架（战略分析）+ 管理思维 + 思维模型（系统/博弈）。
- **组织与团队诊断**：管理思维 + 思维框架（组织管理）+ 心理效应（群体效应）。
- **创新与问题拆解**：思维框架 + 跨学科心智工具 + 思维模型（创新类）。
- **个人成长与学习习惯**：成长思维 + 心理效应（学习与记忆）+ 东方智慧。
- **中西对照**：东方智慧 + 通过 `search` 找到的对应西方模型条目。

## 概念重复与引用规则

- 全库有 188 组同名条目、228 条冗余（约 11.6%），源于多次批次合并。同一概念在不同维度常有不同视角，因此保留多份正文；一次回答只引用一个最贴合的维度，需要对照时再引第二个并说明视角差异。
- `scripts/index.json` 的 `duplicate_name_groups` 列出全部同名组，配合 `search` 逐一比对。
- 标题编号是历史遗留：存在分类内重置、全局连续、889 起编、批次混排四种口径，**不得作为引用键**；统一使用脚本 `ID` 或 `references/文件:行号`。
- 「相关概念」是纯文本而非链接；跨维度联动通过 `search` 显式检索，不假定存在跳转。

## 条目格式

主模板为 `### 序号. 中文术语 (English Term)`，字段为 `**释义** / **核心机制** / **典型应用场景** / **相关概念**`。读取时按实际字段取值，不假定字段一定存在：

- 认知偏差 / 心理效应：部分条目另有 `**精辟释义**`。
- 思维模型 `**来源/创始人**`；跨学科工具 `**来源学科**`；东方智慧 `**来源流派**`（多数无英文术语）。
- 论证谬误：`**分类 / 典型示例 / 识别方法 / 相关谬误**`，关联字段名与其它库不同。
- 思维框架：手写批次含 `**核心机制 / 典型步骤/组成要素 / 相关概念**`；新增批次改用 `**核心问题 / 应用步骤 / 来源/创始人 / 相关框架**`，且缺 `核心机制`。
- 管理思维 / 成长思维：另有 `**分类 / 创始人/来源**`。

字段对照、覆盖率与分类明细见 `references/catalog.md`。

## 数据质量

- `mental_models.md`：573 条 `来源/创始人` 为占位文本「跨学科通用」、322 条 `释义` 与 `核心机制` 逐字重复、90 条 `典型应用场景` 为统一模板句。
- `thinking_frameworks.md`：180 条为套壳「应用步骤」批次，缺 `核心机制`，其中 176 条来源为占位文本；前 55 条为手写条目。
- `cognitive_biases.md`：新增批次 56 条的 `精辟释义` 与 `释义` 重复（字段中的 Python 列表字面量已清洗）。
- 这些条目全部保留，不删除既有知识；但其机制、来源、场景字段信息量低。引用时优先选手写批次，需要机制说明时换用其它维度同名条目或自行补充，不把模板句当作证据。
- 运行 `python3 scripts/lattice.py audit` 复核上述基线；新增或修改条目后重跑 `audit` 与 `index`。
