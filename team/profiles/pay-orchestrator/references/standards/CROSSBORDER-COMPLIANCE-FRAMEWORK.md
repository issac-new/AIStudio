## 二、跨境人民币结算框架

### 2.1 演进时间线
- **2009-07**: 跨境贸易人民币结算试点（上海/广州/深圳/珠海/东莞）
- **2011**: 扩大至全国
- **2022-07**: **大幅简化**，《中国人民银行关于支持外贸新业态跨境人民币结算的通知》（**银发〔2022〕139 号**，2022-07-21 施行）——支付机构跨境业务办理范围拓宽，境内结算银行可直接为跨境电商等外贸新业态提供经常项下人民币结算
- **2024-03**: 跨境人民币结算便利化措施（优质企业凭指令结算）

### 2.2 核心机制
| 机制 | 说明 |
|------|------|
| CIPS（人民币跨境支付系统） | 2015-10 上线，直参/间参模式；2024-06 已覆盖 180+ 国家/地区 |
| 跨境人民币资金池 | 跨国集团人民币集中运营（主办企业制） |
| 人民币境外清算行 | 港澳/东南亚/欧洲/中东等 30+ 清算行 |
| RQFII/QFII | 人民币合格境外机构投资者（2020 合并） |

### 2.3 CIPS 业务规则（关键参数）
- **直接参与者（直参）**: 需在 CIPS 开设账户，含中资大行/外资行在华分行/国际组织
- **间接参与者（间参）**: 通过直参接入，含中小银行/支付机构
- **清算模式**: RTGS（实时全额）+ DNS（定时净额）
- **币种**: 纯人民币（CNY/CNH 均可）
- **与 SWIFT 关系**: CIPS 采用 ISO 20022 报文标准，SWIFT 作为报文通道之一（非唯一）

### 2.4 跨境人民币结算试点管理（2022 简化后）
- **原则**: 企业凭指令结算，无需事前审核
- **例外**: 敏感国家/敏感行业/大额交易仍需事后报告
- **对公**: 经常项目 + 资本项目（证券投资/外商直接投资/外债）
- **对私**: 个人年度 50 万元人民币额度（等值）+ 真实背景审核

## 三、外汇管理框架

### 3.1 基本原则
| 项目 | 要求 |
|------|------|
| 外汇登记 | 资本项目交易需事前登记（FDI/ODI/外债/跨境担保） |
| 额度管理 | QDII/RQFII/QFII 有额度，跨境人民币资金池有额度 |
| 真实背景 | 经常项目凭指令，资本项目需登记 + 核准 |
| 账户隔离 | 经常项目外汇账户 + 资本项目外汇账户 分开管理 |

### 3.3 支付机构跨境外汇业务（汇发〔2019〕13 号《支付机构外汇业务管理办法》，2019-04-29 施行）
- **准入**: 支付机构向注册地外管分局办理**名录登记**后可经营跨境外汇支付业务（原试点机构 3 个月内完成登记）；银行满足交易信息采集、真实性审核条件可参照办理凭交易电子信息的结售汇
- **额度**: 经常项目凭客户指令办理，单笔等值 **5 万美元**以下便利化办理（**注意**: 早期试点口径为"单笔 5 万美元、年度累计 50 万美元/人"，2019 年 13 号文已改为名录登记制+业务范围管理，实际额度与范围以《支付机构外汇业务管理办法》现行有效条款及外管局最新公告为准）
- **资金池**: 境内备付金账户 + 境外托管账户
- **隔离**: 客户资金与机构自有资金严格隔离

## 四、支付机构跨境业务合规要点

### 4.1 牌照资质
| 业务 | 资质 |
|------|------|
| 跨境人民币结算 | 央行支付业务许可证 + 跨境人民币结算业务资质 |
| 跨境外汇支付 | 外管局**名录登记**（汇发〔2019〕13 号《支付机构外汇业务管理办法》） |
| 跨境银行卡收单 | 央行银行卡收单业务许可 + 跨境业务备案 |
| 香港/新加坡等 | 当地 MSO/SVF/MAS 牌照 |

### 4.2 合规义务
1. **客户身份识别**: KYC 全流程，含非居民客户
2. **交易背景审核**: 经常项目凭指令，资本项目需登记/核准文件
3. **大额报告**（央行令〔2016〕第 3 号《金融机构大额交易和可疑交易报告管理办法》，2017-07-01 施行）四档阈值: 当日单笔或累计——现金收支人民币 **5 万元**/外币等值 **1 万美元**；非自然人账户转账人民币 **200 万元**/外币 **20 万美元**；自然人境内转账人民币 **50 万元**/外币 **10 万美元**；自然人跨境转账人民币 **20 万元**/外币 **1 万美元** → 报央行反洗钱监测分析中心
4. **可疑报告**: 同上办法（2016 年发布）——异常交易模式监测分析后提交可疑交易报告
5. **数据本地化**: 境内交易数据存储在境内（数据安全法+个人信息保护法）
6. **年度审计**: 跨境业务专项审计报告，报送监管

### 4.3 外汇资金池管理
- **资金池模式**: 主办企业 + 成员企业（跨国集团）
- **额度**: 净流入/净流出 各设上限
- **用途**: 集团内资金调拨/贸易结算/外债偿还
- **隔离**: 资金池账户与其他账户隔离，专款专用

## 五、数据跨境合规

### 5.1 法律框架
| 法律 | 生效 | 关键条款 |
|------|------|---------|
| 数据安全法 | 2021-09-01 | 数据分类分级、重要数据出境安全评估、核心数据管制 |
| 个人信息保护法 | 2021-11-01 | 个人信息出境 3 种合规路径：安全评估/标准合同/认证 |
| 网络安全法 | 2017-06-01 | 关键信息基础设施（CII）运营者数据本地化 |

### 5.2 数据出境 3 种合规路径（PIPL 第 38 条 + 2024 年新规）

> ⚠️ **2024-03-22 起，《促进和规范数据跨境流动规定》（网信办令第 16 号）已改写原评估办法/标准合同办法的阈值口径，与新规不一致的以本节为准。**

**第一步：先看豁免（免予申报评估/订标准合同/认证）**：
- 数据不包含个人信息或重要数据（国际贸易/跨境运输/学术合作/跨国生产制造/市场营销等场景）
- 境外收集产生的个人信息入境处理后再出境，未引入境内个人信息或重要数据（"数据仅过境"）
- **合同必需豁免**：跨境购物/寄递/汇款/**跨境支付**/开户/机票酒店预订/签证/考试等履约必需
- 人力资源管理按依法制定的规章制度必需
- 紧急情况保护自然人生命健康财产必需
- 非 CIIO 当年累计出境 **<10 万人**个人信息（不含敏感）
- 自贸区负面清单外数据（负面清单机制：天津/北京/海南/上海/浙江/广西/江苏/重庆/福建等 9 地已发布）

**第二步：未豁免的按数据类型 × 当年累计人数走路径**：

| 数据处理者类型 | 当年累计出境规模 | 应履行义务 | 审批/管辖 |
|--------------|----------------|----------|----------|
| CIIO（关键信息基础设施运营者） | 任一个人信息/重要数据出境 | **安全评估** | 国家网信办（经省网信部门申报） |
| 非 CIIO | 出境**重要数据** | **安全评估** | 同上 |
| 非 CIIO | ≥100 万人个人信息（不含敏感） | **安全评估** | 同上 |
| 非 CIIO | ≥1 万人**敏感个人信息** | **安全评估** | 同上 |
| 非 CIIO | 10 万~100 万人个人信息（不含敏感） | **标准合同 或 认证**（二选一） | 省网信办备案 / 认证机构 |
| 非 CIIO | <1 万人敏感个人信息 | **标准合同 或 认证**（二选一） | 同上 |
| 非 CIIO | <10 万人个人信息（不含敏感） | **豁免**（无前置义务） | — |

> **计数规则**（网信办答记者问）：①按自然人人数计（非按条数）；②豁免情形的数据量不计入累计。**支付机构注意**：跨境支付业务属"合同必需豁免"典型场景，但仅限个人作为一方当事人的履约必需信息；机构间数据（如商户结算数据涉及个人身份部分）不适用该豁免。

**其他要点**：
- 安全评估结果有效期 **2 年 → 3 年**（可申请延长 3 年）
- 豁免 ≠ 免除 PIPL 义务：告知、**单独同意**、个人信息保护影响评估（PIA）仍须履行
- 重要数据认定：未被相关部门/地区告知或公开发布为重要数据的，无需作为重要数据申报

### 5.3 金融行业特殊要求
- **数据本地化**: 金融数据原则上境内存储（JR/T 0197 重要数据/5级数据不可出境）
- **跨境传输审批**: 金融重要数据出境需央行+网信办联合审批
- **支付数据**: 支付清算数据原则上境内处理，跨境支付涉及的个人金融信息需单独评估

## 八、版本与时效（2026-09-06 核验更新）

- 截至 2025 年底，中国跨境监管框架总体稳定，2026 年或有新规
- CIPS 二期扩容、跨境人民币可自由使用（2025-06 已覆盖 180+ 国家/地区）
- 支付机构跨境外汇业务仍在收紧，重点关注外管局最新公告
- **数据出境新规衔接**: 《促进和规范数据跨境流动规定》（网信办令第 16 号，2024-03-22 施行）改写出境阈值口径（见 §5.2）；《网络数据安全管理条例》（国务院令第 790 号，2025-01-01 施行）提升数据安全义务层级
- **金融数据安全部门规章双轨**: 金规〔2024〕24 号（金融监管总局，2024-12-27 施行）+ 央行令〔2025〕第 3 号《中国人民银行业务领域数据安全管理办法》（2025-06-30 施行，7 章 56 条）——跨境业务场景下的数据分类分级、高敏感数据管控义务已由部门规章落地（详见 JRT0197/JRT0171 文档时效节）
