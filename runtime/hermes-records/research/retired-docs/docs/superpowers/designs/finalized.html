v12 是按对象模型一次性重排的整稿，不再叠加。概念只有四个：会话（沟通发生地）、循环（持续工作流，阶段与门是其属性）、任务（工作单元，挂靠会话与循环）、参与者（员工与智能体）。沟通协作视图三栏各司其职且唯一：左栏=工作流导航（会话∪循环统一列表，选中谁中栏就工作谁）；中栏=选中对象的工作区（会话→对话画布，循环→运行画布[实时|历史]）；右栏=任务与决策（等我队列就地动作+挂接任务+动态）。管理（任务/会话/员工/智能体/团队）收进状态栏 ⚙ 全局管理台，不占工作视图。六条标准动线见 §4：沟通对齐→指派→执行追踪→决策→编码→管理。IDE 工作台以工作空间维度（任务/项目/会话/链路）绑定同一编码环境。

§2.1操作动线（六条标准流 · 全部可点跳转）

① 沟通对齐：左栏选会话 → 对话画布 → @提及参与方；系统事件（指派/阶段/门）自动入流，聊天即档案。
② 指派：输入区 /指派 #任务 给 @成员，或右栏 ＋新任务/行上改派——指派只有一个视图（右栏+管理台同源）。
③ 执行追踪：左栏选循环 → 运行画布实时视图（LIVE loop graph+阶段+门）→ 切「历史」看事件编年+回放步进（事件跳代码/会话）。
④ 决策：右栏「等我」或注意力条 → 验收/打回就地完成 → 门状态更新 → 对话流与时间线自动留痕。
⑤ 编码：任务行 ⌨ / 链路条「在 IDE 打开」→ IDE 任务空间；IDE 维度条切 任务/项目/会话/链路，⇄ 回协作。
⑥ 管理：状态栏 ⚙ → 管理台（任务/会话/员工/智能体/团队）——实时徽章进列表，行上操作，详情跳运行历史与 IDE。

§4v12 架构总表（对象 → 位置 → 动线 → 跳转）
