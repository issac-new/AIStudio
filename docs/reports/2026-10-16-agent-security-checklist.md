# 智能体安全检查清单

> 整理日期：2026-10-16
> 来源：外部安全审查材料两段粘贴（OCR 转录）
> 整理说明：仅修正 OCR 错字并统一编号，检查项内容未增删。

## 一、检查要解决的问题

智能体赋权过高是本次检查针对的主要风险。已知问题有三类：

1. 部分智能体开发时未遵循最小权限原则，获得了过高权限；
2. 权限分配未根据任务场景动态调整；
3. 智能体与系统、API 集成时，权限传递和边界控制不严。

围绕这三类问题，检查共设 6 个域、20 项。六个域依次是赋权治理、身份凭证、工具与数据权限、系统指令控制、审计、异常控制。

## 二、使用方法

1. 逐项检查，每项结论三选一：符合、不符合、不适用。
2. 判定只认证据：配置项、代码扫描输出、日志记录。口头说明不作依据。
3. 判为不符合或不适用的项，在备注栏写明情况和证据位置。
4. 检查完成后填写第四节汇总表，不符合项须明确整改责任人与完成期限。

## 三、检查清单

### A 赋权与权限治理（3 项）

赋权治理回答三个问题：权限给了多少、按什么调整、传出去后边界在哪。

| A2 | 权限分配根据任务场景动态调整 | □符合 □不符合 □不适用 | |
| A3 | 智能体与系统、API 集成时，权限传递和边界控制严格 | □符合 □不符合 □不适用 | |

### B 身份与凭证管理（4 项）

本域四项要求：无明文、有时效、专号专用、不公开暴露。

| 编号 | 检查项 | 结果 | 备注 |
|---|---|---|---|
| B1 | 禁止硬编码凭证：代码、配置文件、镜像中无任何明文密码 | □符合 □不符合 □不适用 | |
| B2 | 凭证具备时效性：所有 API Key、服务账号（ServiceAccount）均设置有效期，建议不超过 90 天；不存在永久有效的长期凭证 | □符合 □不符合 □不适用 | |
| B3 | 人机权限分离：智能体独立使用专用服务账号，不复用开发人员个人高权限账号 | □符合 □不符合 □不适用 | |
| B4 | 最小化网络暴露：智能体所用的数据库、服务均开启 IP 白名单或应用层认证，拒绝无来源限制的公开访问 | □符合 □不符合 □不适用 | |

### C 工具与数据权限粒度（4 项）

本域限定智能体能执行什么动作、能查询哪些数据。

| 编号 | 检查项 | 结果 | 备注 |
|---|---|---|---|
| C1 | 读写分离与操作分级，按风险对工具定级：只读类（查询、GET）直接放行；写入类（增删改、POST/PUT/DELETE）单独审批或强制限流；高危类（Shell 执行、系统命令、物理删除）默认禁用，启用须经安全审批 | □符合 □不符合 □不适用 | |
| C2 | 数据行级权限隔离：数据库查询强制携带租户或用户标识（如 where tenant_id = ?），不存在不加条件即可查询全量数据的工具接口 | □符合 □不符合 □不适用 | |
| C3 | 禁止直接暴露底层指令：工具封装层不向模型暴露 exec、os.system、Runtime.getRuntime() 等原生系统调用，所有工具调用均为白名单 | □符合 □不符合 □不适用 | |
| C4 | 文件系统沙箱限制：涉及文件读写时，智能体仅能访问指定工作目录（如 /workspace），无法读取系统目录（如 /etc、/root）或用户私有目录 | □符合 □不符合 □不适用 | |

### D 系统指令与操作控制（3 项）

本域在调用现场拦截高危动作：红线固化、高危审批、多跳衰减。

| 编号 | 检查项 | 结果 | 备注 |
|---|---|---|---|
| D1 | 系统指令强制锁定：System Prompt 最顶层固化不可逾越的安全红线（严禁执行系统命令、严禁读取密钥文件、严禁操作其他用户数据），且对用户不可见、不可覆盖 | □符合 □不符合 □不适用 | |
| D2 | 高危操作人工审批门禁：对写入类、高危类工具调用均设置人工二次确认（Approval Gate），须由真实用户点击确认后方可执行 | □符合 □不符合 □不适用 | |
| D3 | 多跳权限衰减原则：主智能体调用子智能体时权限只减不增，子智能体获得权限不得超过主智能体当前权限，严禁反向继承或扩大 | □符合 □不符合 □不适用 | |

### E 审计能力（3 项）

本域保证每次工具调用可回溯、异常有告警、日志有留存。

| 编号 | 检查项 | 结果 | 备注 |
|---|---|---|---|
| E1 | 全链路操作日志：每次工具调用记录五个必填字段，即用户身份或会话 ID、具体工具名、传入参数（脱敏后）、执行结果状态、调用时间戳 | □符合 □不符合 □不适用 | |
| E2 | 越权与异常告警：配置异常检测告警，如单次会话工具调用超过 100 次/分钟、非工作时间（0 至 6 时）的高危操作、调用黑名单工具等情形，须触发实时告警 | □符合 □不符合 □不适用 | |
| E3 | 日志覆盖范围完整，留存时长满足要求 | □符合 □不符合 □不适用 | |

### F 异常控制能力（3 项）

本域回答一个问题：出现异常时，系统能否发现。

| 编号 | 检查项 | 结果 | 备注 |
|---|---|---|---|

| F2 | 告警配置规则齐全 | □符合 □不符合 □不适用 | |
| F3 | 告警有效 | □符合 □不符合 □不适用 | |
