## 三、新增：IDE 全能力自检

入口在命令面板（⌘K / Ctrl+K）的「IDE 自检（全能力冒烟）」。它不改会话、不改仓库、不改配置，只把 IDE 主链路串成一张报告：

- **15 个只读探针**：覆盖会话库、活动会话、工作区、会话深链、辅助页签。另含文案完整性、文件列表、Git 状态、资源管理器、斜杠命令、自动化、模型目录、工作流、上下文档案、Worktree。
- **结果分级**：通过、告警、失败。503/401 属依赖未起或鉴权边界，记告警。500、超时、结构缺失记失败。单项 15 秒超时。
- **可复制报告**：每项带状态、耗时、明细，复制后可直接贴进复盘或缺陷单。

当前环境实跑结果：13 通过、2 告警、0 失败。两条告警分别是工作流引擎未启动（503）与存储扫描部分分类超预算（显示下限）。它们都属于环境状态，不是产品缺陷。

## 五、残留风险与边界

1. **Markdown 媒体仍受 query token 限制**。消息里的本地图片、音频、视频仍以 `getDownloadUrl` 作为 `src`，安全加固后这些 `<img>/<audio>/<video>` 请求会 401。下载按钮已修，媒体内联预览未修，原因是需要把媒体读取改成鉴权 blob URL，属独立改造。锚点：`packages/client/src/components/hermes/chat/MarkdownRenderer.vue` 第 283、301、315 行。
2. **工作流页签依赖外部引擎**。引擎未启动时页面显示「工作流引擎未启动」，不是缺陷。自检把它记为告警。启动命令：`npm run zcode:serve`。
3. **登录默认落点是旅程页 `/app`，不是 `/app/ide`**。这是当前 IA（D18 旅程首页）的设计选择，未按旧设计文档改成 IDE。如需改回落点，应作为产品决策单独处理。
4. **文件 API 的根目录沙箱**拒绝 `~/.hermes-web-ui` 下的路径。新建会话已改 scoped，不再产生该路径。历史遗留的 global 会话仍可能触发 400，需要时手工迁移或删除。
5. **新草稿会话的 404 轮询**来自上游 chat store，`loadLatestDiff` 的本地草稿守卫只减少了一处来源。它不阻塞操作，但控制台会周期性出现 404。
6. **本轮验证在浏览器开发链完成**，未做桌面端装机验证。涉及 Electron 主进程、IPC、原生模块的行为不在本次覆盖范围。
7. **一次既有测试抖动**：`simulation-node-executors.test.ts` 曾因两次 `Date.now()` 相差 2ms 在深比较中断言失败。单独重跑与最终全量均通过，判定为时间敏感抖动，与本轮改动无关。
