## 二、概念内核：主动性 = 行使被授予的「残差决策空间」

全文最硬的贡献不是 6A，而是把主动性放进一个可判定的位置（Figure 2，p5；§2.1，p7）：

> 任务执行空间＝显式规定部分 ＋ **未规定的残差决策空间**（residual decision space）。主动性是「在残差空间内行使被授予的裁量」——自行判断规格没写的地方该怎么做并动手，且不需要为每个决定再要一条指令。

残差空间里具体有四类东西（Figure 2 图注，p5）：**权衡取舍、程序缺口、意外情况、重新规划**。这四类正好是「指令没写、但做事必须决定」的全部内容，也解释了为什么主动性不是「更努力执行」，而是「填补规格的空白」。

论文用**不完全契约**（incomplete contracts，引用 Coase 1937 / Grossman-Hart 1986 / Hart-Moore 1990，p9）给出经济学解释：prompt/指令/常设目标可视为人→机的契约式授权，它无法写尽未来所有状态；未规定状态出现时，**剩余控制权归谁**——机器填，还是把控制权交回人——就是主动性的核心问题。

由此派生出三条贯穿全文的区分：

| 区分 | 论文原话/位置 | 工程含义 |
|---|---|---|
| 主动性 ≠ 自主性/权限 | 「proactiveness 是填补空白的能力，autonomy 是对这些判断授权行动的权力」（p12 §3.8） | 能力与许可分开建模；高能力低授权是合法配置 |
| 形式权威 ≠ 真实权威 | 引 Aghion & Tirole（1997），p46 §5.3.3、p111 §7.2.3 | 用户「有权拒绝」但信息/默认值/时序都在 Agent 手里时，真实权威已转移——控制感评估要看**实际可纠正性**，不是看按钮在不在 |
| 校准化主动性 | 按不确定性、风险、时机、偏好、权限调节介入（p7 引言） | 不是「少问多做」，而是**该出手时出手、不该出手时克制** |

另外 Figure 3（p9）把三件事摆成互补能力：intelligence 提供推理执行、alignment 约束行为对齐人、proactiveness 提供「发现值得做的事并自行发起」；三者合成 **earned autonomy**（挣来的自主权）——授权是靠可靠性挣的，不是一开始就给的。

## 三、谱系与历史：主动性是「越来越不完整的授权」

§2.3（p8，Figure 4）给出光谱：**reactive（响应）→ mixed-initiative（协助）→ self-initiated（自发起）**，对应人的角色从 **operator（操作员）→ collaborator（协作者）→ reviewer（审阅者）**。要点是：

- 光谱不是等级制，**同一个 Agent 可以在不同时间尺度上处在不同位置**（车辆刹车是响应式，规划充电站是自发起式）。
- 现实系统几乎都是**混合式**：快反应层（time-critical）+ 慢思虑层（长时程预测）。
- 「该问的问题不是它有多主动，而是它被允许多主动、在什么条件下、有什么护栏」（p8）。

§3（p9-12）用七条传统解释「为什么早期主动性受限、后来逐步可委派」：控制论（固定目标下的自触发）→ 规划/世界模型（先模拟再行动）→ BDI/agent 理论（承诺与主动性）→ 普适/上下文感知计算（持续情境模型）→ 混合主动交互（介入的经济学）→ 目标推理/内在动机（生成议程）→ 基础模型（开放式重组）。**七条线各自解决了残差空间的一块**，这个视角对我们判断「某个能力是不是真新增」很有用：多数「新机制」是旧传统在新基底上的重述。

## 四、6A 机制（§4，p13-33）：每项的可操作要点

### 4.1 Awareness（p14-18）
- 四个子能力：多模态状态跟踪与上下文管理（p14）、主动感知与信息检索（p16）、分层记忆（p16）、**运行时架构：触发器、常开监控、sleep-time compute**（p17）。
- 关键约束：常开监控有**能耗/时延**代价（p100 §6.14.2 讨论快慢双系统），所以工业界做法是分层——便宜的常开监视器打标签，重要/含糊/高风险时才升级到贵处理（p102 §7.1.2 明确写成本文建议的架构）。

### 4.2 Anticipation（p18-20）
- 三个模型：用户模型（意图与心理状态，p18）、世界模型（环境动态与未来预测，p19）、**反事实推理：这笔介入值多少**（p20）、生成式场景模拟「心智沙盒」（p20）。
- 论文把「比较介入 vs 不介入的后果」放在**预判**层而不是裁决层——意味着它是**估值**动作，裁决只是消费这个估值。

### 4.3 Agenda（p21-24）
- 三步：从**潜在需求生成显式目标**（p22）、子目标提议与长时程议程（p23）、**目标优先级与冲突解决**（p23）。
- p24 给出一句很关键的边界：多目标管理一旦进入「谁来抢占这一轮」就成了**仲裁**问题——排序决定「最想做什么」，仲裁决定「准不准做」。这与我们已有的两轴模型分工一致（两轴＝许可，治理者＝时机）。

### 4.4 Arbitration（p24-28）：四道门，顺序固定

这是全文对工程最直接的一节，Figure 10（p25）给出四门串联：

| 门 | 判据 | 不过门时的动作 |
|---|---|---|
| ① 不确定性与置信（p24） | 我对「用户需要」的把握够不够 | **澄清或索取信息**（clarify/seek），不是简单丢弃 |
| ② 价值 vs 成本（p26） | 预期收益是否超过成本；成本按行为性质计价：建议/提醒＝**用户注意力**，环境动作＝资源、副作用与风险 | 抑制或延后 |
| ③ 时机（p26-27） | 成本是**非平稳**的：任务断点最便宜、思考中途最贵；系统侧看窗口与提前量 | 不丢弃，而是**协调交付**：立即/协商/中介/定时；骑现成断点（opportunistic） |
| ④ 风险与可逆（p27-28） | 我可能错，这个动作够安全吗 | 软门：**权限随后果强度成比例**；硬门：外部策略否决；两者都不行→**优雅地什么都不做**（intelligent disobedience） |

四节里有四个我们上一版没吃到的洞见：

1. **② 的成本是「按行为性质」定价的**，不只是「打扰次数」。建议类花注意力，环境动作花资源与风险——用同一把预算尺子量两类事是错的。
2. **② 还要折现未来接受度**（p26）：单次看净正、序列上烧掉用户愿不愿意听（cry-wolf / false-alarm → automation disuse）。所以效用模型必须**折现未来 receptivity**，只算当次收益会系统性高估。
3. **③ 的「不丢弃而是协调」**：错的时机不等于该取消，而是换交付方式（immediate / negotiated / mediated / scheduled）；最优雅的做法是**骑已有断点**（用户本来就要停下的地方）。
4. **④ 的「优雅地不动」是校准结论，不是失败**；且硬门必须在 Agent 判断之外（权限系统/护栏），因为「风险感知本身是弱环节」——前沿 agent 在沙箱里照样无标记地做不可逆动作（p28 引 Ruan 2024 / Yuan 2024）。

### 4.5 Action（p28-31）
- 两个决策：动作前做多少活（复用权限谱系，p28）、怎么呈现（p30 混合主动交付）。
- 交付要求：**范围与状态清楚、可确认、可编辑、可撤回、失败可恢复**（与 p42-43 §5.2.5 的评估面对应）。

### 4.6 Adaptation（p31-33）
- 三块：隐式反馈与自我纠正（p31）、推理时反思（p32）、**长期校准、个性化与信任**（p33）。
- p33 的核心警告与摘要版一致但更具体：**只奖励「被接受」会把系统训练得更能说、而不是更有用**；需要诚实地呈现依据与不确定性，并允许用户纠正**触发这次行动的记忆或规则**。

## 五、评估三层（§5，p34-46）：可抄的指标清单

论文把评估拆成三层，且每层给了**可直接落地的指标名**——这是全文对我们最有操作价值的部分。

### 5.1 任务层（p37-38）
- 成功：目标完成、正确性、相关性、风险降低；**允许多种合法响应**（给信息/澄清/准备动作/部分完成/适当地沉默）——所以不能用单一「完成率」判。
- 效率：任务时间、交互步数、token/计算；收益必须抵得过成本。
- 会话级分数会掩盖归因，建议**介入级打分**（intervention-level scoring，p37）。

### 5.2 机制层（p38-44）
- 4 项：上下文建模（p39）、用户/世界状态预判（p39）、规划质量（p40）、**介入决策与时机（p41-42）**、**介入交付与呈现（p42-43）**、适应与泛化（p43-44）。
- 介入决策的指标（p41-42）：
  - 介入 precision / recall / F1、**false intervention rate**、**missed assistance rate**、多决策类型的 macro-F1；
  - 澄清与同意：**unnecessary question rate**、**missed clarification rate**、consent-seeking accuracy；
  - 授权分配：autonomy coverage、deferral accuracy、selective risk、**risk-coverage curve**、expected decision cost、calibration error、Brier score；
  - 时机：**expected interruption cost**、resumption time、interruption 后的 performance loss、subjective disruption、receptivity prediction accuracy；
  - 反面：**toxic proactivity**（追任务时违反安全约束的频率）、productive engagement / passive ignoring / active disruption 三类反应要分开报（p42）。

### 5.3 用户层（p44-47，Table 2 四维）
- **User Workload**（p45）：NASA-TLX 类主观负荷＋时间/步数客观量。
- **Usability & Experience**（p45-46）：SUS/UEQ；以及**有用性-侵入性-隐私的三方权衡要分开报**（p46）。
- **Level of Control**（p46）：override 频率与成功率、修改成功率、**reversal cost**、对控制边界的理解、**名义权威与真实影响的差距**。
- **Trust & Reliance**（p46-47）：**appropriate reliance 四象限**——正确接受/正确拒绝/错误接受/不必要拒绝；外加 verification behavior、error detection、维持适当怀疑所需的努力；信任轨迹与 **trust AUC**（p47）。

## 六、13 域与编码域专章（§6，p47-100）

- 13 域：编码、GUI、信息获取（搜索/推荐）、具身与机器人、安全与监控、AutoResearch、智能家居、智慧城市、医疗、法律、教育、娱乐媒体、农业；末节三条跨域趋势（p97-100）。
- **三条趋势**：① 共享架构 + 域内特化；② 从「协助人」到「承接工作流」（人的角色从 operator→collaborator→reviewer）；③ **验证与反馈基础设施是关键约束**——能给廉价可靠反馈的域（软件：编译器/类型检查/测试/CI）进展最快。
- **编码域（§6.1，p47-52）与 AIStudio 最相关**，结论很直接：
  - 现状：**Awareness 与 Action 已经强，Arbitration 正在变强；真正的大缺口是项目级的 Anticipation、Agenda、Adaptation**（p47）。
  - 「工作在别处被选中」是当前边界：issue/看板/触发决定做什么，Agent 只在这一范围内规划执行（p47）。
  - **发现与执行可以解耦**（p49）：只负责「提出候选工作」的 Agent 不需要执行权，输出应是**有证据的工程主张**，由项目决定接受/延后/拒绝——这正好是我们 delivery 建议应当的形态。
  - 度量发现的门槛：发现必须是**可被独立决策的关切**（可接受/延后/拒绝）；修 bug 时发现的架构弱点是发现，完成本任务的隐含步骤不是（p49）。
  - 风险与协调：介入与协调按**纠正成本**治理——在授权硬边界内，Agent 可以做多深取决于「理解程度 × 回滚保证」，超出就澄清或升级；目标不是最大自主，而是**校准且可纠正**（p51）。
  - 长时程 stewardship（p51-52）：跨会话承诺靠**仓库即记录系统**＋结构化进度产物；交接的价值在于「让下一个 Agent 能决策」，而不只是「总结上一个做了什么」（引 Handoff Debt）；压缩策略要保住承诺、证据、被否假设、未解问题与恢复条件。

## 七、摘要版没给、全文给了、并且改变我方判断的六点

| # | 全文的说法（页） | 上一版我们的实现 | 结论 |
|---|---|---|---|
| 1 | 四门顺序固定，第一门不过要**澄清/索取信息**（p24-25） | 只有 suppress/defer，没有 clarify | **要补**：低置信应产出「先问」而不是「先压」 |
| 2 | 成本按行为性质计价：注意力 vs 资源/风险（p26） | 统一按「打扰条数」预算 | **要补**：两类干预分别计价，不能共用一把尺 |
| 3 | 效用要**折现未来接受度**（cry-wolf，p26） | 只有同话题拒绝退避 + 近 1h 密度惩罚 | **要补**：全局 receptivity 衰减（近期忽略/拒绝比例） |
| 4 | 时机错了要**换交付方式**（立即/协商/中介/定时），并骑现成断点（p27） | 只有安静时段延后 | **部分补**：支持调用方传断点提示；交付方式留字段 |
| 5 | 风险门要**软门按后果成比例 + 硬门在 Agent 之外**；不可逆且等待便宜时「优雅不动」（p27-28） | 只有 severity/urgency；不可逆靠两轴权限 | **要补**：治理者接 reversibility/blastRadius，输出 hold |
| 6 | 评估要报 **missed assistance / false intervention / clarification rate / appropriate reliance 四象限 / trust AUC**（p41-47） | 只有接受率/忽略率/撤回率/信任校准差 | **要补**：precision、missed（延后未投递）、澄清率、四象限拆分 |

另外两条不改代码但改口径：
- p42 明确要求**拒绝要能区分「决策错」还是「交付差」**——我们的台账里 rejected 只记结果，没有归因字段，计分卡解读要谨慎。
- p46 的**形式权威 vs 真实权威**提醒：我们的「可反馈按钮」不等于用户真有控制权；控制感只能靠「能否在后果发生前介入 + 纠正成本」来评估，这一点我们目前**没有可测数据**，只能如实标注为未采集。

## 八、对 AIStudio 的结论

1. **我们上一版的方向是对的**：把注意力轴与权限轴分开、把决策与反馈落台账、按三层出计分卡——全文逐条支持（§4.4、§5.3）。
2. **但上一版是「摘要版精度」**：四门压成了规则优先级，缺了 clarify 这一档、缺了按性质计价、缺了未来接受度折现、缺了可逆性门与 hold、缺了发现侧的 missed/false 指标。这些不是锦上添花，而是「校准化」这个词的实际内容。
3. **编码域的缺口与全文一致**：我们强在 Awareness/Action（观测、执行、门禁），弱在**项目级 Agenda（议程）与发现评测**。上一轮挂账的三项（发现测试、Agenda、Anticipation）在全文里被独立确认为编码域的主要开放方向（p47、p52）。
4. **验证基础设施是我们的相对优势**：§6.14.4 说反馈廉价可靠的域进展最快；AIStudio 有全量测试、门禁、评测集、证据留痕——这意味着同样的主动性机制在我们这里**更容易被验证**，应当把这个优势用在主动性上（介入级打分、消融、反事实）。

## 九、第二批增量（本报告落地，均已实现并测试）

1. 治理者四门化：`confidence` 门（低置信 → `clarify`）、`value/cost` 门（按 `kind: attention|resource` 分别计价）、`timing` 门（安静时段/断点提示 → `defer`，带 `nextWindowAtMs`）、`risk` 门（`reversibility`＋`blastRadius` → `hold`/`escalate`）。
2. 未来接受度折现：`receptivity` 由近期 ignored+rejected 占比派生，直接折减分数（cry-wolf 的工程近似）。
3. 计分卡补 4 项：介入 precision、missed assistance（延后未投递）、clarification rate、appropriate reliance 四象限拆分。
4. 台账记录 `decision` 增 `clarify`/`hold` 两档；反馈增 `dismissed_reason`（decision 错/交付差/时机错）以支撑 p42 的归因要求。

- 参考文献约 1400 条未逐条核；本报告引用的一律是正文出现处（含原始文献名），未回源核实原文结论。
- 用户层四维里 **workload/control/trust 的真人数值我们一条都没有**：我们的计分卡是系统行为代理指标，不等于用户感受。要拿到真数据必须做真人实验，本轮不做。
