# IDE 侧栏组织模式修正：项目真归类 + 分组空态引导（spec）

日期：2026-10-19
分支：`fix/ide-organize-accuracy`
来源：用户走查——会话按「分组、项目、时间线」的分类显示不对。

## 变更

1. **「项目」真归类**（新 `utils/sessionProjects.ts` + taskGroups project 分支重写）：
   - 引擎内部工作区（`~/.hermes-web-ui/coding-agent/workspace/...`，末段是 global/scoped 模式名）与空 workspace → 「未绑项目」兜底桶（置底）；
   - 真实路径 → 目录名（末段）为项目名；项目按最新会话逆序。
   - 实数据锚：coding_agent 会话 workspace=内部目录（曾显示伪项目「global」）；cli 会话 workspace=null（曾全落伪分组「默认」）。
2. **「分组」空态引导**：无任何自建分类时，「未分组」桶内渲染一行创建引导（任务菜单「移动到分组 → 新建分组」），不再像分类失效。label/testid 不动（引导是独立元素）。
3. **「时间线」**：上一批已改时间分层（今天/近 7 天/更早），本批无改动，实测正常。

## 决策记录

1. **未绑项目是诚实兜底而非猜项目**：会话数据里没有可靠的项目字段（workspace 两类脏值）；从消息内容猜仓库路径误报率高且不稳定。真实 scoped 会话（workspace=真实路径）自动归对。
2. **内部目录按标记识别**：`/coding-agent/workspace/` 路径标记，不比对完整前缀（home 目录可变）。
3. **引导不进 label**：分组 testid 以 label 拼装（既有测试锚），提示作为节内独立元素渲染。
4. **未绑项目置底**：有内容但非目标态的兜底桶不与真项目抢位。

## 验证

- 单测：session-projects 3 例（内部目录/真实路径/空值）；task-sidebar 更新未绑项目断言；IDE 全套 118 文件 / 718 用例过；构建通过。
- 真实浏览器（done 视图，3 会话）：项目=「未绑项目 (3)」（伪 global/默认消失）；分组=「未分组 (3)」+引导；时间线=「近 7 天 (3)」。
