## 二、问题清单（P1-P10，按严重度排序）

### P1【方案-产品脱节】承载面清单引用的路由在 v0.7.30 已不存在

- **现象**：V8 §2.5 步 5/7/24 承载面写 `#/app/gov`（治理中心六列表单/G1 工件区/平级真页签五分区）；实测 v0.7.30 前端全量路由表（25 条，从懒加载 chunk 提取）**无 /app/gov、无 /app/dash**，治理域已并入 `/app/settings` 分层（设置·账户管理 roster@91e4b8b 实拍证实）。步 4 承诺的「运行中心工作流页签」所在的运行中心列表本身是空态（见 P6）。
- **初衷对照**：治理中心是"一等公民界面"初衷的核心承载；方案把它锚在死路由上=该初衷在正本里不可执行。
- **根因**：V8 正本成稿于 v0.6.46→v0.7.30 升级轮（2026-10-05/06）之间，§2.5 沿袭 V6/V7 的路由事实，升级改版（驾驶舱改版/路由收敛）后未回灌校验。
- **修正**：附录 F-1「承载面路由锚版本校验」——正本引用的每条路由在起跑前预检时实弹校验（HTTP 200+目标组件渲染），失效路由按附录 F-2 降级口径处理并记单；正本侧本条更正待产品侧确认治理域最终归宿（settings 分层 or 独立路由回归）后随附录 F 落版。

### P2【初衷级旁路】假设 1 的五个产品面，三个被 harness 绕开

- **现象**：假设 1 承诺"沟通=Matrix 聊天、任务=看板、审批=收件箱、度量=治理中心、编码=IDE 工作台"。run9 实况：**沟通**=Matrix API 直采（产品客户端不显示驱动所建房间，见 P6）｜**审批**=群内 `!approve` 反应审批（审批收件箱面未演练）｜**度量**=导演侧脚本生成 governance-report（治理中心度量面未运行，六域台账停在 run2 时代）｜任务=看板 ✓（卡 ID 与 state 双侧对账）｜编码=CLI agent 作业、IDE 仅走查帧。
- **初衷对照**：SwarmStudio 初衷是"为可监督性设计的**产品**功能"——run9 证明的是 V8 假设 2（治理机制链）与 564 修复，假设 1 的产品面承载只部分成立；报告 PART1 披露了房间/注册表两条缺口，但没有按"五面承载"框架系统披露，读者会高估产品承载程度。
- **根因**：harness（mx-* 调度/API 驱动）与产品（studio 驾驶舱）是两套并行体系，方案未定义"哪些步必须在产品 UI 内完成"的硬边界，导致 API 旁路永远是最省力路径。
- **修正**：附录 F-3「产品面承载率」指标——五面各计 UI 实拍/操作证据，报告 PART1 增承载率行；run10 目标承载率 ≥4/5（编码面允许 CLI 作业+IDE 走查组合）。

### P3【报告错误归因·已实测反转】步 25"简报抽屉 canvas 点不开"归因错误

- **现象**：run9 报告步 25 叙事/图注写"任务简报抽屉不随点击弹出（canvas 限制，如实记）"。本轮对照审计实测：按方案 §2.5 指定入口 `#/app/ide?task=t_e35cd102` 深链，**简报抽屉到达即自动展开**，RACI 四元组/工作流/git/验收字段一屏齐（25-op7-after.png，508KB 实拍）。
- **根因**：收官补拍未按 §2.5 指定入口操作（裸路由+点击），把"没用对入口"误判为"产品限制"——采集执行纪律缺失（§2.5 逐条承载面没有 checklist 化）。
- **修正**（本轮已落地）：报告步 25 叙事/图注 H7 更正+25-op7 帧挂接；r18-steps 步 25 操作条目同步改写；教训入档案件（凡"产品做不到"类结论必须先按方案指定入口复测再下判）。

### P4【采集缺口】步 13 skill 过程展示帧承诺未兑现

- **现象**：§2.5 步 13 明文"xxx-dev 生成 ≥3 帧+开发调用 ≥2 帧入报告"；run9 帧池 66 张无一张 skill 过程帧（swarm yuan 初衷"五步能力可追溯"无 UI 证据，仅 testlog/分支间接可查）。
- **根因**：必采矩阵（r18_matrix）只覆盖对话 5/操作 3/效果 3 共 11 项，§2.5 的步级承载面承诺没有进矩阵、也没有进审计——承诺悬空无人拦。
- **修正**：run10 前置 R25——必采矩阵扩步 13 载荷（生成 ≥3/调用 ≥2 帧硬性），r18_matrix.py+守门测试⑫同步；采集器挂 skill 生成过程事件。

### P5【度量残缺+口径分裂】治理报告只兑现 §2.6.6 五项度量中的一项，且与 PART1 口径不一

- **现象**：§2.6.5/6 要求"各闸一次通过率、证据一次通过率、缺陷密度、打回次数、AI 贡献口径"五项+「下次推演目标即上次基线+1」机制。run9 governance-report metrics 仅一行：`首过率,4/4（G1首过 G2首过 G4首过 G5首过）`——①G3/G6（落键型闸）不计入分母，与 PART1 手写"6/6 全首过"口径分裂（两处都未声明分母定义）；②其余四项度量缺席；③基线对比行缺失（run8 对照是导演手写进 PART1，非机制产出）。
- **修正**：run10 前置 R26——gov_report 度量面补齐五项+读上轮 metrics-log 生成基线对比行；首过率分母口径统一（六闸全计或声明评审型四闸）；本轮 PART1 已补口径声明行（见修正二）。

### P6【产品缺口·升格】房间不进客户端列表 + 运行注册表空态——"一等现场"在呈现层断裂、编排双轨

- **现象**（run9 已记单，本审计升格为初衷级）：①驱动所建 Matrix 房间不进产品房间列表/通讯列表（房间同步空态 9-op5 实拍），群聊协作现场只存在于 Matrix 层，产品呈现层看不见——"群聊=分布式协作一等现场"初衷在产品面落空；②运行中心列表空态+RunDetailView 404（runs-registry-empty 记单）——产品本有运行中心/循环引擎（loop+graph patch 472、工作流页签、Observatory 全链路追踪）专为编排运行设计，但 mx-* harness 自建调度体系旁路了它，**两套编排体系并行，产品编排面成摆设**。
- **修正**：产品 backlog（挂 issues+档案件）：a) 房间列表同步驱动所建房间（或提供"运行房间"过滤视图）；b) runs 注册表接入 mx 运行（mx-up 落 run-progress 时同步写注册表）；c) 长线评估 mx 调度语义下沉产品运行中心（编排单轨化）。

### P7【采集面真相未入正本】hash 路由/canvas 点击不穿透/多视角采集三教训停在记忆层

- **现象**：run9 补拍批 k=1 因 path 形式 URL 全落默认会话页报废重拍；看板 canvas 渲染 DOM 点击不穿透；帧互异最终靠"多账号视角+多路由"实现。三条实测真相只在会话记忆与档案件 §五，方案 §2.5/§5.6 未收录——run10 采集还会踩。
- **修正**：附录 F-2 采集纪律条款（详见修正二）；r18-frames.mjs 文档头注记三真相。

### P8【审计盲区】审计器无承载面符合性查项——P1/P3/P4 全部漏网

- **现象**：mx-report-audit 核对标题/把关行/图存在性/md5 唯一/锚点/R18 三载荷，但不查"该步的 §2.5 承载面是否有对应帧或记单声明"。步 5 承载面（治理中心表单）实际拍的是设置页、步 25 指定入口未用、步 13 帧缺——审计全绿放行。
- **修正**：run10 前置 R27——审计器新增承载面符合性查项（从 §2.5 派生按步 checklist：承载面帧在位，或该步有 issues 记单声明降级，二者其一；缺者 WARN 起步、连续两轮 FAIL 转硬）。

### P9【治理边界】越序抢跑是闸后甄别非事前拦截；RACI 双@走非同源通知

- **现象**：五 agent 越序抢跑 8 分支（agent-prework-bypass-g2）由 G2/G3 闸后甄别兜住；RACI 双@×4 走回灌通道非房间 @派发。"治理靠机制不靠自觉"（假设 2）在这两处是事后记账不是事前拦截——agent 依 run8 记忆自治行动时，指令序位（G2 前不开工）与通知同源（房间 @）没有机制强制。
- **修正**：run10 前置评估——prework 门禁前置（看板卡 ready 状态在 G2 落键前不派发 spawn 信号，或 dispatcher 增加 gate-guard）；RACI 通知同源复验（已在 DISP 延后项）。

### P10【呈现折扣】PART2 术语规范违例——"第三方可懂"假设打折

- **现象**：假设 3 与 §5.4 要求报告对不熟悉项目者可懂；V8.2 候选已立"内部代号首现必须给全称或一句话解释"负面清单但未生效。PART2 实况违例：步 2 叙事"564/533/534/390/391 五补丁"无首现解释、多处 state.env/sset/relay/mx 系代号未释义（PART1 的 564 有解释，PART2 机器叙事漏）。
- **修正**：V8.2 候选条款随附录 F 先行落入 §5.4 报告规范（生成器侧 STEPS_META 叙事写作约束+审计器术语抽检候选）；本文档修正一已同步补步 2 释义。
