# 前端页面设计重规划·视觉与布局收敛（呈现层正本）

日期：2026-10-16
状态：v1——基于浏览器实拍诊断的呈现层重规划；信息架构不动（需求冻结锚定的三中心+岛屿+七签结构维持）
上游依据：设计正本《2026-10-16-design-derived-from-requirements.md》（信息架构）＋实拍走查帧（2026-10-16 隔离实例九面走查，artifacts 存档）

## 〇、三句话主旨

用户在浏览器实看推演中心旗舰屏后提出「重新规划前端页面设计」——重规划对象是**呈现层**（布局壳与视觉语言），不是信息架构（三中心已被需求锚定且刚完成九面真数据走查）。本档给三层收敛方案（壳收敛/设计语言基座/旗舰排版）分三批落地，V1（壳收敛）随本批交付。读完应能回答：用户看到的三个视觉问题各由哪层收敛、每批改哪些文件、验收怎么测。

## 一、实拍诊断（问题定位，帧=2026-10-16 走查）

1. **双导航体系并存**：推演中心页左侧仍有上游 `StudioNavigationRail`（单聊/群聊/工作流/历史/设备互联/模型/用量/API 中继一排）——三中心导航已立，旧 rail 在推演/治理页属重复导航+视觉噪音；其入口语义属工作台沟通域。
2. **顶栏工具条过长**：任务徽章/在线/日程/版本/账号/看板直达一字排开，与三中心导航抢视觉层级，主次不分。
3. **主区缺乏设计语言**：数据全但排版朴素——KPI 数字平铺无卡片化、26 步表为浏览器默认表格、无字号层级与留白节奏、状态色未成体系，「工程原型感」强于「产品感」。

## 二、三层收敛方案（分三批）

### V1 壳收敛（本批交付）
- 推演中心（/app/sim 家族）与治理中心（/app/gov 家族）页面挂载时 body 加 `ia-center-full` 类，卸载移除；overlay 全局样式隐藏上游 rail（`.studio-navigation-rail { display:none }`）——**CSS 收敛零补丁**，不动上游 App.vue 显隐逻辑。
- 工作台（/app）V1 保留 rail：沟通域的单聊/群聊直达在工作台有导航语义；是否收敛随 V2 评估（见决策 D2）。
- 验收：两中心页面 rail 不渲染（DOM 断言）；工作台页不受影响；往返切换类正确增删。

### V2 设计语言基座（下批）
- 设计 token 表：色彩语义（fresh 绿/stale 琥珀/fail 红/pass 深绿/compensated 紫正式化为 CSS 变量单一事实源）、字号四级（页题 15/区块题 13/正文 12/辅助 11）、间距节奏（4 的倍数）、卡片统一（边框+圆角 6+内距 10/12——现有散件样式已在用，抽公共类）。
- 顶栏工具条分组收纳：状态徽章组（任务/在线/日程）折叠为一条状态胶囊，版本/账号入角标——释放视觉层级给三中心导航。
- 工作台 rail 去留评估（对照走查帧）。

### V3 旗舰屏排版升级（末批）
- KPI 四卡卡片化（数字大号强调+标签辅助+状态色左边条）；姿态横幅加图标与更强色带；26 步表按七幕分组视觉分段（幕头色带行）；净额卡紫标区与代偿列表分层呈现。
- 验收：截屏对照（与 2026-10-16 实拍帧并排）；无障碍对比度抽查（WCAG AA）。

## 三、不做（边界）

- 不动信息架构（三中心/岛屿/七签/路由）——需求冻结域；
- 不引入 UI 框架（保持原生样式渐进增强）；
- 不做暗色/亮色双主题新增（沿用现有深色态）；
- 不动上游文件（全部经 overlay 样式/组件层）。

## 决策记录

- D1（V1 范围）：壳收敛先做推演/治理两中心，工作台保留 rail——理由：实拍问题发生在推演中心页；工作台是沟通域，rail 入口有导航语义，收敛需单独评估动线（V2 决策）。
- D2（V1 手段）：CSS 隐藏（body class+overlay 全局样式）而非 patch 上游 App.vue 显隐逻辑——理由：零补丁零上游耦合，revert 成本一条样式；rail 的 DOM 仍在（无功能删除，对账 123 行零删除红线不触碰）。
- D3（分批理由）：三批依「视觉痛点大小×改动面风险」排序——壳收敛痛点最大改动面最小先做；设计 token 涉全局面随后；旗舰排版逐屏打磨末做。每批独立可验收可回退。
- D4（V2 基座已交付，785e8823 之后本批）：设计 token 单一事实源落 overlay 全局 ia2.scss（:root 五态色+字阶四级+间距 4 倍数+卡片规范）——与上游变量共存不覆盖，散件样式同值反推成表；顶栏状态胶囊=任务+在线两 chip 合容器（SitlineBar 挂 .ia-status-capsule 容器类），释放层级给三中心导航。
- D5（V2 边界）：不改上游组件结构，胶囊经容器类+overlay 规则实现；日程/通知/版本/账号保持原位（功能不删，动线不变）。
- D6（V3 已交付）：旗舰屏排版三改——KPI 数字大号化+分母辅助+状态色左边条（闸=pass 绿/含代偿=stale 琥珀/净额=compensated 紫，与 D4 token 同源）；26 步表七幕分段头行（幕名+步号区间）；样式基座经 token 引用不写死色值。VTU 6 例（含四 fetch 全 mock 的装载等待——OverviewPanel 装载链四端点任一未 mock 即 loading 卡死，属测试基建坑非产品缺陷）。
- D7（V2 挂账清偿批）：①WCAG 对比度抽查落地并校准 token——深色主题（现用）文字级 AA 全过：fail #d33→#e06666（原 3.61）、pass #1d6b40→#2f9e6e（原 2.54）、compensated #9a6ac9→#9678c6（原 4.15 仅大字）、stale #c9962e→#b8860b（浅底补足 3:1）；对比度纯函数+双底断言入 visual-shell 机械把关（token 手改漂移即红）。②工作台 rail 去留评估定案=收敛——八入口中六项有强替代通路（设置侧栏/FlowNavPanel/治理·系统设置），聊天主动线在工作台左栏聊天列表；WorkbenchView 挂同款 body 类（33K 重型壳不做整挂载单测，grep 守门同 scss 模式）。三中心全宽一致达成。
- D8（壳层全盘重规划，2026-10-16 用户走查三点质疑）：①顶栏岛屿组整体退役——BPA（流程治理）/本体（语义资产）/技能治理（功能治理）/评测（质量治理）退出顶栏，归**治理中心壳头「治理工作台」区**（模块入口按钮组，feature 门控随行）——四者皆治理域工作台，家在治理中心；顶栏唯一导航层级=三中心。②IaViewSwitcher 文案消歧：「IDE 工作台」→「IDE 画布」（collab 态显示目标；ide 态显示「沟通协作」）——它是工作台中心的两种形态切换（沟通协作⇄IDE 画布），非第四个中心，撞名即歧义。③顶栏终态=品牌+三中心+全局搜索+状态胶囊+通知+主题/语言+版本+账号。
- D9（顶栏合并，2026-10-16 用户走查：「工作台和 IDE 画布是一个东西，顶部栏合并」）：「工作台」中心按钮升为**分段控件**（沟通协作｜IDE 画布 两段，同属工作台中心；中心激活时整体高亮、当前形态段加深），URL 上下文随行语义原样承接（会话 id 跨形态携带）；IaViewSwitcher 品牌簇挂载退役（isIde 判定与切换逻辑并入分段）。顶栏概念终态=三中心三按钮，「第四个入口」彻底消失。
- D9b（实现勘误）：分段 v-if 键名以 CENTER_NAVS 注册表为准（'workbench' 非 'work'）；活体验证=两段渲染+当前形态高亮+旧切换器零残留。
