# Swarm Studio 信任与归属纠偏实施（2026-10-19）

## 一、目标与边界

本批只做“让页面说的是真的、让对象只有一个写入口、让状态可恢复”，不新增业务能力。

- 不新增一键启动、自动预检、真实 G5 发布审批、UAT 持久化。这些属于能力工作包，待后端契约就绪后另批实施。
- 不改 R1-R14 / N1-N8 需求语义，不重开已在 2026-10-18 定稿的左栏五组与六阶段骨架。
- 旧路由全部保留重定向，零断链。
- 只改 overlay/，不修改 upstream/。

## 二、P0：阻断误导

### 2.1 完成度口径

`CockpitOverview` 的交付进度改为：

- 显示“已完成 n / 总数 m”原始计数；
- 百分比向下取一位小数，只有 `done === total` 时才显示 100%；
- 文案明确这是“全部看板任务”，不是当前运行；
- 保留进行中、评审中、受阻、未开始分项。

### 2.2 G5 只收发布准出类审批

`ApprovalPanel` 新增 `filter?: 'release'` 属性：

- 仅保留 `kind='review'` 且标题/详情命中发布、准出、G5、release、上线、发版语义的条目；
- 历史与抽检区同样过滤；
- 过滤后为空时显示“当前没有发布准出类审批”，并给出“查看全部审批（收件箱）”入口；
- 普通命令审批与普通评审不出现在 G5 页签。

不把 terminal_exec 或普通评审改名成发布审批。

### 2.3 名称兑现能力

- 删除②“启动运行”页签与 `launch` 组件映射；启动仍由 harness 执行，入口保留在“启动准备 → 全流程推演”。
- ⑤“UAT 判定”改名“UAT 待判”，`TracePanel` 在该模式下明确“只读清单，不在此录入判定”。
- ⑤ G5 页签保留名称，但空态与说明明确只展示发布准出类审批。

### 2.4 IDE 文件页权限错误

当 `validation.message` 命中 `super administrator` 时：

- 内容中文化：“当前工作区根目录需要管理员权限”；
- 提供“去选择任务工作区”（看板）和“查看账号角色”（系统设置）两个动作；
- 保留“重试”。

### 2.5 版本预览与设置页

- `gov-settings-registry` 将 `hermes.versionPreview` 标为 `superAdmin: true`；
- `entryVisible` 对 `versionPreview` 同时检查功能开关与路由存在；
- 设置页移除“原生/旧族”来源徽标和对应说明，改用用户语言的功能分组；
- 设置项标签去掉内部括号说明（如“九页签”）。

## 三、P1：归属与状态

### 3.1 ④审批统一展示

新增 `StageDevApprovals` 组件，同屏分两块：

- 人工介入与遗留项（`GatekeeperSection`）；
- 普通审批与评审（`ApprovalPanel`，不带 release 过滤）。

两块各自显示真实计数，不再以其中一块的 0 代表全部审批为 0。

### 3.2 ③文档范围

`GovDocsReviewView` 增加 `scope?: 'g2'`：

- G2 页签只渲染质量门工件与待裁决评审；
- 应用资产登记、组织权限矩阵不在 G2 文档页重复编辑，保留“到①组织/环境与资产维护”的说明与跳转；
- ②/⑥保持全量文档评审。

### 3.3 状态恢复

- BPA 六页签、本体八页签、技能治理两页签写入 `?tab=`，刷新/分享/后退保持；
- 检索持久化类型与筛选条件（工作区/状态/负责人/时间），不把检索词写入 URL（避免敏感内容进入历史与日志）；
- 非法 tab 回退默认页签。

### 3.4 窄屏

- 视口 ≤720px 时强制紧凑侧栏，不受用户历史展开偏好影响；
- 页面主内容在 ≤720px 改单列，头部操作换行；
- 继续保留桌面优先定位，不在本批承诺完整移动版功能等價。
