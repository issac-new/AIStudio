# AIStudio 检索弹窗真值修复规格

- 日期：2026-10-27
- 状态：实施中
- 分支：`feat/global-search-dialog-truthiness`
- 关联：`2026-10-27-global-search-consolidation.md`

用户实报：检索弹窗页签「名不副实」。活体逐页签测定出四个真值问题。其中人员与工作区两项在旧检索页同样存在，本批一并根治。

1. 人员页签恒空。数据源是团队房间注册表（matrix 房间 state events 投影），本环境为空数组。
2. 运行页签空态无解释。日常实例 run 库真空（运行在推演实例隔离库），0 是真值，但通用空态让用户以为坏了。
3. 工作区筛选有 699 个绝对路径选项。选项与任务 workspace 一一对应，大量一次性 `workspaces/t_*` 目录。旧语义还会把文档/人员整体清零。
4. 0 计数徽标隐藏。页签点得动但看不到 0，看起来像有数据。

## 变更

1. **人员源换真源**。主源改为治理仓 roster 文档（`docs/admin/roster.md`，①搭建·账号页同一真源）。团队注册表账号并入，按归一化账号名去重。解析复用 `fetchRegistry` 与 `parseFirstTable`。roster 装载与文档索引同款 store 层缓存：一次会话只取一次，失败回落注册表账号、不猜数。点击行为不变（直达账号页预选定位）。
2. **运行空态给去向**。空态文案改为「日常实例暂无运行记录，运行在全流程推演专区查看」，附「去全流程推演」按钮。徽标规则维持大于 0 才显示。
3. **筛选拉直换轴**。工作区筛选退役，改为「看板」筛选：任务按板过滤，会话经挂接任务反查所属板。文档与人员不属于板维度，不再整体清零。任务与会话行元信息同步改显板名，推演板标注「（推演）」。旧深链 `ws` 参数不再消费，关闭时一并清理。
4. **0 徽标如实显示**。选中页签时该页签徽标 0 也显示。全部徽标维持真值。
