# 驾驶舱减负第二批：常用入口常驻、来源阶段高亮、中心归属回链（spec）

日期：2026-10-17
分支：feat/cockpit-quick-nav-context
来源：用户对上一轮列出的后续项下达「彻底完成后续」。上一轮四项痛点已由 9d64ab17 + 37c72d45 收口；本批完成其后可逆部分：日常四入口常驻、旅程/阶段落点按来源高亮、两个中心显式归属阶段并可一键返回。

## 变更内容

1. **常用入口常驻条**：新增 `ia2/components/IaQuickNav.vue`，挂在 `IaGlobalTop` 页头下方，常驻显示四个日常高频目的地——审批收件箱、看板、运行总览、监督面板。当前页高亮并带 `aria-current`。此前这四个入口分散在阶段工具卡与两个中心的页签里，跨页往返需先记路径再点多次。
2. **来源阶段上下文**：新增 `stageKeyFromQuery`/`activeStageForRoute`/`stageContextQuery`（`nav-centers.ts`）。从旅程页 A 区步骤（`from=1`）或阶段页工具卡（`from=<阶段号>`）进入中心/末端页时，顶栏高亮按来路阶段；无来路或非法值回退路径归属。中心页签切换、面包屑回中心、仿真设置/场景编排返回均保留 `from`。
3. **中心归属回链**：仿真中心页头新增「← ④开发」、治理中心页头新增「← ⑥治理」，点击回所属阶段并清除 `from`；两个中心不再只是六阶段之外的第三层孤岛。
4. **顶栏假高亮根治**：④开发分段里的「沟通协作」子按钮原先无条件挂 `seg--cur`，导致任意页面同时出现「当前阶段」与「④开发」两处选中视觉。改为仅当 `activeStage === 'stage4'` 时高亮。
5. **i18n 守门修正**：覆盖测试把岛屿路由名（ia2.bpa/ontology/eval/skillgov）当作文案键误报；路由名集合补入 `ISLAND_NAVS`，与既有的“路由名非文案”豁免同义。

## 决策记录

1. **不动路由骨架**：本批只加导航层与上下文，不把仿真/治理中心的路由并入六阶段。全量拆轴会改 URL、深链与八个契约测试，属于需用户单独裁定的架构变更；本批先消除「同一页面两处高亮」「往返重打路径」这两个具体伤害。
2. **来源阶段用 query 而非全局 store**：`from` 可分享、刷新保持、跨窗口不串味，也无需清除逻辑；非法值由 `stageContextQuery` 过滤，不写脏参数。
3. **快捷条放全局壳而非各页复制**：单一挂载点覆盖全部 `/app` 页面；独立窗口（standalone）走 IaPopoutBar，不渲染全壳，因此不重复。
4. **中心回链只回阶段首页**：不猜测用户具体从哪个工具卡来；阶段页本身可再用工具卡回到中心签，形成双向闭环。
5. **不动数据面**：快捷条零数据依赖，不新增端点调用；不引入新的轮询。
