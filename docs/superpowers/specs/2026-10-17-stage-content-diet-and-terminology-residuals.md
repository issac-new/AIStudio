# 阶段页减负与术语残留清理（spec）

日期：2026-10-17
分支：`feat/ia-stage-content-diet`
来源：用户再次明确「页面有太多导览性质的内容占了很多篇幅」「菜单及功能名称要符合行业标准术语体系」。本轮以 8649 真实浏览器逐页走查为证据，只修用户可见的占比与用词问题，不改路由结构、不改推演引擎、不新增端点。

## 走查证据

1. `/app/stage/design`（③分析设计）正文长度 123,913 字符，是其余阶段页（283-899 字符）的百倍量级。根因是 `GovOrgKnowledgeView` 整块常挂：五流断点诊断、知识图谱、决策图谱与交接词典全部展开，阶段页的核心工具卡被推到首屏之外。
2. `/app/stage/build`（④开发）中 `HandoffSection` 的「四种类型 × 五种状态」参考词典占半屏，挤压容量告警与审批待办。
3. `/app/sim`（仿真中心）顶部 `SimFlowStrip` 三张大卡各带一句说明，属于导览性质占位；文案仍用「开轮」「姿态」「清偿门」。
4. `/app/stage/build`、`/app/stage/govern`、`/app/gov`、`/app/inbox` 均出现同一问题：`GET /api/hermes/orgloop/ledger → 503` 时，`GatekeeperSection` 的 `Promise.all` 整体失败，人工介入队列（本可正常取数）被一并拖死，页面只显示「清偿台账未配置（ORGLOOP_LEDGER_TSV 缺席=fail-closed）」。
5. 注意力条首行仍显示英文标签「swarm kanban」，提示文案仍写「双击」；旅程首页仍有「驾驶舱概览」「A 区｜」「B 区｜」；`SimSettingsView` 仍有「姿态缺省」「开轮」；治理中心仍有「语义体检」「工程效能」；运行总览仍有「机器执法实况」；看板/治理页仍有「评审闸口」「任务工厂模板」。这些词在 2026-10-17 术语映射表里已有标准译名，属遗漏。

## 变更内容

### 一、阶段页减负

- ③分析设计：`GovOrgKnowledgeView` 改为按需展开，默认不挂载。区块保留标题、一句用途说明与「展开查看」按钮；展开后才 mount，收起即卸载。阶段页首屏回到「阶段标题 + 本阶段内嵌核心件 + 工具卡」。
- ④开发：`HandoffSection` 包进原生 `<details>`，摘要为「交接类型与状态说明（参考）」，默认收起。容量灯与审批待办保持在首屏。
- 仿真中心：`SimFlowStrip` 从三张带说明的卡片压缩为一行文字流程「启动准备 → 运行监控 → 运行复盘」，只保留当前阶段高亮与直达按钮，不再渲染每段说明。

### 二、审批待办部分失败隔离

- `GatekeeperSection` 的 `Promise.all` 改为两路独立取数：介入队列与遗留项台账分别记录成功/失败。台账失败时，介入队列照常渲染，台账区单独显示错误与刷新入口；反之亦然。
- 台账 503 的原始错误保留在 `title` 属性，正文显示人话「遗留项台账未配置，请联系管理员配置清算台账后重试」。
- `ClearancePanel` 同样对人话化台账错误做展示，原始错误进 `title`。

## 决策记录

1. **按需展开而非删除**：`GovOrgKnowledgeView` 与 `HandoffSection` 仍是阶段页的合法操作面（设计正本 D15 明确要求内嵌），删除会丢功能；改为默认收起、按需挂载，兼顾「首屏可用」与「能力可达」。不引入新路由，不新增接口。
2. **默认不挂载而非仅 CSS 隐藏**：③页整块组件会并发拉取多路治理数据，仅折叠仍会消耗请求与 DOM。用 `v-if` 控制挂载，收起即卸载，避免后台无意义取数。
3. **审批队列与台账解耦**：一个数据源 fail-closed 不应让另一个可用队列陪葬。这是「部分失败如实呈现」的落地，不是降级绕过：台账错误仍显示，只是不再阻断介入队列。
4. **错误人话化保留原始锚**：正文给人能懂的原因与下一步，原始服务端错误放 `title`，排查时可悬停查看，不隐藏事实。
5. **术语以 2026-10-17 映射表为准**：只修用户可见字面量；「旅程」是体验设计隐喻、不是交付生命周期标准词，用户可见标题与面包屑根改为「流程总览」，组件名与路由名保持 `JourneyView`/`ia2.journey` 不动。26 步登记表是推演方案正本的逐字副本，保持原文以维持追溯，不在本批改动。页签文案的测试断言同步更新。
6. **零路由/零接口变更**：本批只动 `custom/client` 的组件与文案，采集位、直达链接、API 契约全部不变。
