## D.4 用户反馈规则（45 条，按类）

### 交付闭环与验收（8）

| 规则 | 根因 | 判据 |
|---|---|---|
| 「合 main」≠「已生效」，须三档实证 | 10 项根治仅 5 成立；检测器未部署 | 部署产物 grep/进程 pid+时间/事件字面触发 |
| 测试未绿禁 commit/push/deploy | vitest 1 failed 仍提交 | 测试与提交分轮；全绿后单独提交 |
| 验收命令必须递归+交叉 | ls-tree 不递归误报 6/6 缺 | 所有 ls-tree 加 `-r`；第二命令复核 |
| 根治=修产生缺陷的层 | 只修场景技能被追问 | 先问哪层放进来的；未实战称待验证 |
| 台账空带先查来源覆盖 | 6.24-9.10 断档不实 | 空带先查 spec/plan/提交；只补可反查条目 |
| 每轮当轮实时截图 | run10 零采集收官补拍 | capture 焊驱动；零帧拒出报告 |
| 闸 FAIL 唯一出口=打回上游复审 | run20 G2 拆闸被推翻 | 真派修订→commit→复审 PASS |
| 工作流义务须机器可读状态键 | 「push 后复审」只写散文悬空 75 分钟 | 状态键+超时检测+催办限 3 次 |

### 汇报、语言与决策（7）

说人话结论先行；巡检三句+完成度三桶；每轮哨巡四动作（进展/问题/ETA/观察）；收尾编号决策清单每项一句建议；黑话门禁必跑 HARD=0；门禁须扫自己写的正文；文档终稿态无脚手架。

### 协作、并行与工作树（6）

双哨只读验收失联才接管；共享主树分支是共享可变状态（提交前查分支/稳定节点小步提交）；同树并行 spec 当权威+只动不相交文件；未经明确指令不 push；网关只监控不拥有；定时自动化不能自删。

### 派发、静默与任务粒度（5）

assignee 用工人档案名+ready+@；群令 ≤4 步极简单步令；判静默看工具计数/产物/大窗口日志；全员静默先查监督器+驱动双活；任务拆到 30 分钟可独立完成+独立 commit。

### 文档结构、产品与演示（9）

方案一事实一源/标题无赘述；重规划先全量盘点再对账；人名用职能称呼；md/docx/pdf 一致；设计文档 30 agent 口径；overlay 是核心、simharness 按产品引擎缺陷同清偿；推演程序只管启停/模拟审批/监测/轮间修；并行是平台默认能力；演示真实素材>装饰、稳定>炫技。

### 工具链与构建（10）

桌面只出 mac arm64 dmg+win x64 zip；运行中禁改主脚本（原子 rename）；patch 禁手改 hunk；Bash cwd 会静默重置；heredoc 写中文会乱码；`local` 仅函数内；zsh 不对变量分词；vite 中文注释+regex literal 崩；第三方 dist 缺类型本地复刻；rtk 过滤列表会丢归属。

## D.5 二十条最高价值规则

1. 「已落地/已生效/已根治」必须给部署产物、运行时进程或字面事件三档之一；commit 不算生效。
2. 测试未绿禁止 commit/push/deploy；测试与提交分轮。
3. 根治=修产生缺陷的层；未实战一轮只说「待验证」。
4. 未经用户明确指令不得 push 远端。
5. 未经明确指令不得起跑任何推演轮次。
6. 闸 FAIL 唯一出口=真修订+复审 PASS；禁止拆闸。
7. 共享主树是共享可变状态：提交前查分支、小步提交、主树非 main 用临时 worktree；worktree 只走 git 清理。
8. 群令 ≤4 步；assignee 用工人档案名。
9. 任务拆到 30 分钟可独立完成+独立 commit；阈值按真实 session 采样。
10. 全员静默先查监督器+驱动双活；判活看工具计数/API 行/产物，不看 mtime。
11. SIM 快照必须 `build:full`→provision→重启 studio。
12. 服务载体三处同钉：custom 符号链接、vite config、cwd 全指 serve-main。
13. 端口拓扑固定：8801 网关/8802 studio/8647 后端/8649 前端/8008 synapse/15721 cc-switch。
14. 凭据 0600 放仓外；CLI 实测隔离 HERMES_WEB_UI_HOME。
15. 一切输出说人话、结论先行；文档终稿态。
16. 收尾给编号决策清单（事项+建议+保守选项）。
17. 文档一事实一源；重规划先全量盘点再对账。
18. 运行中禁改主脚本；必须改则原子 rename。
19. patch 机械再生+纯净基线重放+逐字节对账。
20. 每轮实时采帧；零帧拒出报告；补拍须透明标注。

补充：台账空带先查覆盖；G5 三路取证+单点终判；并行能力默认、>1 人日即拆解。

## D.6 十二类工程陷阱（工具链）

| 陷阱 | 表现 | 判据/规避 |
|---|---|---|
| Bash 全角吞字 | `$var（` 被 bash 3.2 吞并 | 全角前加花括号；LC_ALL=C 处理中文标签 |
| Bash 空数组/pipefail | 赋值失败静默、管道退出码 | 静态扫描门禁；`set -o pipefail` 审用 |
| `local` 顶层 | code block 搬到顶层 rc=127 | grep local；单点外科替换 |
| zsh 不分词 | `for f in $FILES` 整串单词 | 数组或字面量展开 |
| heredoc 中文 | rtk/tee 双重编码乱码 | 中文用 Edit/Write |
| cwd 静默重置 | 命令跑错树 | 绝对 cd + `[cwd:]` 标记 + lsof 核树 |
| patch hunk 手改 | 文件尾静默丢行 | `diff --no-index` 再生+重放+字节对账 |
| vite 中文注释 | esbuild PARSE_ERROR | 改 `new RegExp`；不在 worktree build |
| 第三方 dist 缺类型 | vite build fail | 本地 interface 复刻 |
| rtk 列表过滤 | 丢目录归属 | find 直列；ps 直查 |
| 日志 mtime 心跳 | 新鲜≠在干活 | 取最后真实 API 行 |
| 进程/端口 pid 文件失真 | pid 文件过期 | `lsof -sTCP:LISTEN` 取真监听 |
