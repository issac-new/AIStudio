# P2 整合批次：推演总览密度、检索类型计数、看板入口说明（spec）

日期：2026-10-19
分支：`fix/p2-density`
来源：《2026-10-19 工作台全页面走查与整合重规划》§四 P2（第 6/8/9 条；第 7 条专题页统一壳未在本批）。

## 变更

1. **推演总览密度**（`OverviewPanel.vue`）：七阶段默认只展开当前阶段，阶段头改为可折叠按钮（箭头 + 名称 + 步区间 + 完成度 n/m）；用户手动切换后不再被自动展开覆盖。右栏改为粘性固定（`position: sticky`），左栏长表滚动时六道门/自动代处理/观察窗入口保持在视野内。
2. **检索类型计数**（`SearchView.vue`）：类型页签带结果数（全部/会话/任务/运行/文档/人员），数量为 0 时不显示徽标。
3. **看板入口说明**（`StageShell.vue`）：③任务分解与④开发看板内嵌的是全量看板，页签顶部加一行说明「与常用·看板同源」并给「在全量看板打开 →」回链，消除三处入口像三个不同看板的误解。

## 决策记录

1. **折叠用 v-show 不用 v-if**：26 行步骤仍在 DOM，既有测试锚（`ov-step-row-N`）与证据抽屉逻辑不变；折叠只是隐藏非当前阶段。
2. **默认展开当前阶段而非全部折叠**：用户最关心「现在跑到哪」，默认把当前阶段摊开；其余折叠把首屏让给 KPI 与质量门。
3. **右栏 sticky 而非独立滚动容器**：页面滚动模型不变，改动只在样式层，避免在已有 `overflow-x: auto` 的主栏上叠双重滚动条。
4. **计数为零不显示徽标**：`0` 与「没有」等价，显示 0 会增加噪音；`v-if="counts[t]"` 已覆盖。
5. **看板入口先做「说明 + 回链」而不是真过滤**：阶段过滤视图需要看板组件接受状态筛选参数，属交互重写；本批先消除「三个看板」的认知歧义，真过滤留待 P2 续批，避免在无回归网的情况下改看板核心。
6. **专题页统一壳（P2-7）未做**：四页体量差异大（技能治理约 6.4 万字符），统一壳是一次独立设计轮，不在本批混入。
