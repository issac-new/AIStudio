### 一、推演方案（设计文档面）V8.55 → V8.56，新增三条运行口径

1. **外部依赖不具备条件时的绕过口径**（三段式）：识别（责任角色在台账点名 `external-unavailable`，写清为何推演域内不具备条件）→ 批准（导演明示，登记批准依据与截止条件）→ 显形（报告第 0 章列出「已批准绕过/缓期」清单）。**缓期≠已完成**；截止条件满足而未补齐时自动回落阻断。run23 首例：Z-2 等保备案受理编号（须向属地公安机关真实递交取得回执，推演域不可自证）。
2. **带缺口放行的显形口径**：G3/G4 以 `g3_evidence_gap`/`g4_evidence_gap` 记录缺口后放行的关卡，报告第 0 章必须写作「✅ 通过（带缺口）」并附警示行。run23 实录：G3 三支分支缺 testlog、G4 遗留红例，若首页只写「通过」即与正文自相矛盾。
3. **报告叙事与按轮事实口径**：步级叙事、六域审计结论、按轮注记**必须按轮注册**（`mux/narrative_<run>.py`、`_DOMAINS_<RUN>`），未注册轮出「未注册」占位，**禁复用旧轮文本/数字**；交付物路径允许「基名+通配」变体命中并显示实际路径。run23 实录两类污染：未注册轮沿用内置静态实测（出现「26/26 步 UI 图在位」「28/28 绿」「55s→20ms」等非本轮数字）；矩阵期望 `DEV-CHWX-testlog.txt` 而实产 `DEV-CHWX-S3-testlog.txt`。
