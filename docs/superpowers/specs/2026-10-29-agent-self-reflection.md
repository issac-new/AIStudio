# Agent 自我觉察与反省能力（长会话治理 B 层）

日期：2026-10-29 ｜ 状态：需求立案（spec 即决策事实源；实现批待 run23 收官后首件）｜ 触发实证：run23 20261028 22:33-00:12 fanfan 中毒会话卡滞 1.5 小时

## 需求背景（实录形态学）

run23 概设稿段：fanfan-agent 会话上下文中毒（76K 历史×长生成＝上游秒死，out=8 token），**agent 自身完全无感**——持续「有调用」却零产物 1.5 小时；外部机制全部失配：驱动催办三次（为犯懒设计，对中毒无效且每次重触发同一毒历史）、runaway 守卫六信号（盯工具环不盯效能比）、会话轮换（只在压缩耗尽/迭代上限触发）。最终靠外部值守人工定谳（调用形态三查）＋删会话干预才解锁（干预后 out=8 秒死变 out=8192 完整生成，一次成功）。

同日值班侧另有一例同构：值守监控以「agent 活性」为进度判据误判三轮，被用户批评后以「产物判据＋催办失败一次即介入＋调用形态三查＋30/60 分钟介入线」四条纪律自我纠偏——**该闭环（觉察自身失效信号→结构化归因→把教训固化为可执行规则）正是本能力要赋予产品内每个 agent 的东西**。

## 能力定义（三层）

1. **自我效能觉察（telemetry）**：运行时按会话统计「有效轮 / 空转轮」——有效轮＝产生产物信号（文件写入、提交、含结论行的消息、板卡状态变更）；空转轮＝短输出（out<50 token）、流不完整终态、零工具副作用。轮次比值与空转连击数作为觉察信号暴露给 agent 自身（回合上下文内可读）。
2. **反省触发（reflection trigger）**：空转连击 ≥3 或「活动时长 × 产物零增」超阈值 → 运行时注入结构化反省回合：「你最近 K 轮调用模型但产物为零，形态为 out=N token/流不完整；请列出可能原因并从处置菜单选择（自轮换会话/拆分任务重报/如实上报阻塞），反省记录将入证据面」。触发与形态数据随回合 sidecar 提供（与 604 检查点同族管道）。
3. **自纠动作面（sanctioned self-actions）＋留痕**：只开放既有产品通道——自我会话轮换（603 机制产品化放开自触发）、任务拆分重报、阻塞如实上报（自动记问题单）；禁止把反省文本当产物充数。反省记录（触发原因/形态数据/所选处置/结果）落 evidence（与 review-record 同族，报告可审计）。

## 决策记录

- **D1 能力归属运行时层（agent 内），不是 harness 层**：导演催办是外部信号，看不到会话内部形态（out token/流终态）；本轮实录证明外部催办对内因性停滞无效。运行时补丁族（401/457/601-605 长会话治理 A 层）已铺好接线基座，本能力为其 B 层（自治理）。
- **D2 觉察判据＝产物信号，不是活性信号**：本轮事故双重根教训（fanfan 以活性掩盖零产出；值守监控同犯）。一切触发条件以产物面（工件/提交/结论行）为准，活性只作对照不作判据。
- **D3 自纠只走既有通道，不新增越权动作**：会话轮换/拆分重报/阻塞上报都是现行机制，本能力只是给 agent 自己的触发权；越权面（改判据、越闸）不开放。
- **D4 反省留痕入证据面**：反省不是日志装饰，是可审计证据（防「假反省真表演」——反省记录须带形态数据与处置结果回执，报告侧可对账）。
- D5 实现批定位：run23 收官后首件（run 中不动运行面树）；落点＝runtime overlay＋vendor 补丁（B 类，走 patches/ series），SIM 快照经既有 deploy/patch 通道自然吃到。

## 验证（实现批定义）

- 单测：空转连击计数、产物信号分类、触发阈值、动作菜单合法集。
- 推演场景验证：注入「中毒会话」形态（大体量历史×短输出秒死）——旧态＝卡滞至外部干预，新态＝≤3 轮空转后自反省→自轮换→产物恢复；反省记录在 evidence 可查。
- 对照指标：run24+ 同形态卡滞时长（预期从小时级降到分钟级）。
