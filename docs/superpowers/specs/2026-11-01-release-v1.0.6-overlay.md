1. **cockpit 进 studio.4、agent-teams 不进位**：补丁 722 虽是 agent 行为修复，但载体文件 `patches/722-*.patch`＋`series` 属 cockpit 包的 packageIncludes（patches/）；agent-teams 包含面（team/＋runtime/＋vendor/hermes-agent）零 diff——沿 v1.0.4/v1.0.5「模块路径 diff 文件数」判据，不按语义归属跨包进位。

3. **ModelScope 形态=资产文件仓库而非 git 整仓镜像**：ModelScope 主形态是文件托管；GitHub Release 的对应物是发布资产。整仓镜像 5.3 万文件无先例且体积大，不采。旧 RELEASE-NOTES（2.x 线时代）「ModelScope 通道同步」措辞无实物可考（tupang 名下仅 tupang/ollama 一仓），本轮按新建仓库处理。
4. **产物分发口径节不随批修订**：「## 产物分发口径」仍写 local-only；连续两轮（v1.0.5/v1.0.6）上传均为用户明示例外。口径是否正式改为「GitHub＋ModelScope 双通道」属立法变更，待用户裁决（本 spec 只登记事实）。
5. **零变更模块照发资产**：agent-teams/yuan-skill/ycode 三个源码包随批重打包上传（内容与 v1.0.5 同源码面、版本号不变），保持 Release 资产完备性；同 v1.0.5「ycode 3.17.1 零变更照发」先例。
