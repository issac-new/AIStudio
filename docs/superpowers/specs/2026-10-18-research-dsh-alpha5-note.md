# dsh 最新标签核对补注（2026-10-18）

**主旨**：调研报告基于共享检出 `dsh-v0.2.1-alpha.2`，而仓库最新标签为 `alpha.5`；本补注用只读 `git log alpha.2..alpha.5` 核对增量并如实标注，避免「最新版」口径失真。

## 决策记录

- D-1：不切换共享检出到 alpha.5。理由=`upstream/deepseek-harness` 是其他会话与推演共用检出，切换标签会改变他人工作树基线与测试夹具；只读 log 足以判定能力族是否变化。
- D-2：版本表格标注「最新标签 alpha.5 / 检出 alpha.2」两值，不把 alpha.2 写成最新。理由=锚点必须可复核；`git describe` 与 `git tag --list` 两条命令分别对应两个事实。
- D-3：增量结论只写 alpha.3–5 的提交主题级变化（账户通知/模型标签/PTC 提示/终端会话/侧栏修复等），不重写 tools-batch2 的能力清单。理由=未发现新能力族，重写会制造「已逐文件核对 alpha.5」的假象。
- D-4：明确后续需要逐文件 alpha.5 对照时应重新 checkout 该标签。理由=本轮是版本口径补注，不是 alpha.5 全量源码测绘。

## 验收

- 矩阵版本行同时出现 alpha.2（检出）与 alpha.5（最新标签）及各自命令锚点。
- 增量段落列出来自 `git log alpha.2..alpha.5` 的主题级变化，并声明未切换检出。
