# IDE 侧栏视图语义修正：进行中/更早/工作空间 + 时间线分层（spec）

日期：2026-10-19
分支：`fix/ide-sidebar-view-accuracy`
来源：用户走查——左栏「进行中/已完成/工作空间」与「分组/项目/时间线」分类不准确、展示名不副实。

## 变更

1. **「已完成」→「更早」**（`IdeTaskSidebar.vue` 本地 VIEW_TEXT）：done 桶口径是「超过 24h 无活动」而非任务完成（会话无完成态字段），词表「已完成」误导；title 写明口径（三视图均带）。文案本地化不改 patch 347 词表（键保留，守卫同步）。
2. **工作空间视图计数口径=会话数**：此前显示工作空间数（「工作空间 1」实为 1 个工作空间），与另两视图口径不一致。
3. **时间线组织真分层**：今天/近 7 天/更早 三段（段内更新时间逆序），替代原「优先级降序平铺单列表」——名叫时间线却无时间维度。
4. **zcode CLI 分组跟随视图与搜索**（`IdeCliSessions.vue`）：active=24h 内、done=更早、workspace=全部；query 命中标题/目录；分组头计数=过滤后条数（组件 emit）；空态区分「库空」vs「本视图无匹配」并给切换指引；拉取上限 12→30。

## 决策记录

1. **改文案不改数据**：分桶纯函数（sessionBuckets）口径不变——活跃窗口推导是诚实的，错在把「不活跃」叫「已完成」；改显示层语义即可，不动桶结构与持久化值（sessionView 'done' 保留，旧偏好无损）。
2. **时间线内排序弃优先级**：时间线的语义就是时间；任务优先级徽标（P0-P3）在行内保留可辨，不再主导排序。
3. **CLI 计数 emit 而非双拉**：侧栏头计数与组件过滤同源（props 进、count 出），避免两处各自过滤口径漂移。
4. **守卫跟随现实**：三视图按钮 v-for 化后 testid 动态拼装，session-views 漂移守卫改锚拼装模板+三键枚举（意图不变：三 chip 接线在位）。
5. **不改 organize 芯片交互**：工作空间视图隐藏 organize（既有行为已正确），分组/项目/时间线三态保留。

## 验证

- 单测：新增 CLI 视图/搜索过滤 3 例 + 视图语义源码守门 2 例；时间线用例改分层断言；IDE 全套 117 文件 / 715 用例过；构建通过。
- 真实浏览器（8654）：三视图文案「进行中 0 / 更早 0 / 工作空间 0」+ done title 口径；active 视图 CLI 30 行（全在 24h 内）；切「更早」IDE 空态 + CLI「没有超过 24 小时的 zcode CLI 会话」；时间线出现「今天」分层段。
