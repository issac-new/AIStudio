## 决策记录

| # | 决策 | 理由 | 否决的备选 | 可逆 |
|---|---|---|---|---|
| G1 | 推送后归还另一会话的登记，而不是保留本批的卡或把卡注销 | 保留本批的卡，对方下次推送会被拦；注销卡片，对方的登记与验收条目就丢了。归还后对方的范围判定与此前完全一致 | 登记后不归还（否决：把问题转嫁给对方） | 是 |
| G2 | 按字节归还，不经命令行重新登记对方的卡 | 命令行重登记会生成新的确认时间并丢掉对方的修订留痕；按字节还原则状态与动手之前完全相同。这不算绕过通道：没有改动对方登记的任何内容 | 用 `qgate intent` 重写对方的卡（否决：失真） | 是 |
| G3 | 不使用豁免，也不使用跳过提交检查的逃生门 | 豁免与跳过检查都属于放宽验收，须用户裁决；登记本批任务卡是门自己规定的写入通道 | `qgate waive`（否决：越权）；`git commit --no-verify`（否决：规避） | — |
