## 决策记录

1. **agent-teams 不进位**（Mechanical）：v0.23.3-team.1（2026-11-20 底座批）后 `git log team/` 零变更——「确保最新版」定谳＝包与底座均已在最新（上游稳定 tag=v0.23.3=钉版）；宿主 profiles 与脱敏正本的 live 漂移（机路径/.env 运行态）按分发语义不回写不盲装（2026-11-18 半套部署崩溃事故先例＋用户立法「推演程序不得影响宿主 hermes teams」）。
2. **cockpit 包口径维持「只发 full＋yuan everything」**（既有裁定）：studio.2 声明前进、cockpit 包不重发。
3. **发版对象双仓分离**（Mechanical）：产品 release 走 AIStudio 仓（v1.0.16 三资产先例）；技能源码包走 Swarm-yuan 仓 v<ver>-src（ecc/gstack/superpowers＋SHA256SUMS，self-check 一键安装消费）；everything 离线包只走 ModelScope（c0bb2bf 口径）。
4. **releaseBatches 台账项打包时回填**（v1.0.16 同款后置）：本提交先做版本进位，打包 commit/tag 定格后补 commit+treeHash 条目。

5. **L1.symbol-grounding 准出红根治（发版轮实录）**：预检双红定谳＝executor 双层缺陷——①resolveSpecifier 只对 scanGlobs 扫描宇宙做成员判定，相对 .json 数据文件（decision-vectors.json）结构性失明；②json 模块无词法导出面，default 导入成员判定整类误报。修＝显式扩展名相对导入走文件系统在位判定（缺席仍 fail）＋json 模块成员判定豁免（在位性已由解析保证）；守门测试两粒度（在位 pass/缺席 fail）随批。
