## 决策记录

1. 未变化的 59 门禁、204 配置变量、`--all-full=32`、R134、state-machine 和 L1-L4 基本结构不写成新增能力。
2. run28 是当前最新完整轮；run27 已完成，run29 尚无完整报告。run28 的含代偿六闸与净额必须分开，净额为 5/6，open 65 和呈现 11/13 不得隐藏。
3. run28 时长以 state.env/运行指标的 44,954 秒（12h29m14s）为准；旧 spec 的 14h29m 只作为不同口径记录，不直接照抄。
4. strict 的 SCHEMA_EPOCH 只兼容历史决策，边界后的新记录仍执行完整 schema；`shortcut:` 挂在既有 check_adr，不增加门禁数。
5. 真实 ACP/Skill E2E 和 acp-server 冒烟是分层证据，不证明每次 worker 都读取目标技能，也不证明引擎一定是 Ycode 分叉。
6. 路由和设计索引均先生成后登记，新 spec 计入后重算；历史 spec 和报告不改写。
7. 全产品文档共用同一版本与事实源：根 README、docs/README、USAGE、intro、DESIGN、设计数字总账、Windows 安装模板和 team 双语说明同步更新。培训手册 marker 生成区只经 `npm run docs:sync` 重建，设计索引只经 `scripts/maintenance/gen-doc-indexes.mjs` 重建，run28 HTML 报告不手改。
8. 路由清单生成器必须包含项目两页；补齐后按真实投影 123 routes＝82 pages＋41 redirects，扣除两个默认禁公开外链后登记默认内容页 80，不沿用漏注册时的 78。
9. run26 的后续完整报告真实存在，不能简化成“只有挂账清偿、不是完整轮”；其 477 分钟、26 步、六闸全过和 G4-E=GAP 作为历史事实保留，run28 才承担当前最新入口。
10. 培训课件、run28 与 swarm-yuan 不再依靠外链拼接：同一 `aistudio-interactive-training.html` 扩展为 14 幕，run28 为索引 12、swarm-yuan 为索引 13。统一目录、步骤流转、稳定场景 ID 深链与 14 页打印；源 Markdown 仅作可选参考，不是课程依赖。
11. 以四阶段 run28 复核工作包取代“主课＋专题附录”：规则与技能（1-4）→执行与验证（5-9）→治理与复盘（10-13）→综合验收（14）。每幕记录 handoff.consumes/produces/next 和 caseEvidenceIds，交接 DAG 与证据注册表驱动目录、当前步骤和打印；末幕回流 product-spec-design。拓扑删除场景下标数组，整幕流线由 stepGuide 并集派生，焦点直接取 scene.focus。此决策取代第 10 条的追加快照。
12. 不只重排和加元数据：全部 14 幕实例改为直接消费 RUN28_EVIDENCE 注册事实。案例定向、G2 钉锚、运行采集、组织派发、技能装载、提交包、G4 打回、黄金集误杀、有效批准、裁决开立、运行事故、审计闭环与综合验收均围绕同一案例；新增守门要求实例正文必须包含本幕注册证据原文。
13. 课件呈现升级为「run28 案件复盘工作台」：主区三行＝四阶段案件路线带（含 26 步、含代偿 6/6 对净额 5/6、open 65/已修 8/65、报告 11/13 对后续帧 13/14 四组冲突数字）＋拓扑调查面（前序浅绿走查态、当前深绿）＋证据附件台（附件签带 snapshot/status/locator，点击回查完整事实；observed 不渲染为通过；切步保留选择、切幕重置）。布局宽度锁进 A4 纸内（`min-width:0/max-width:100%` 链），证据行在纸内滚动而非撑破纸张；打印态证据从页眉迁至页底通栏「证据附件」条（双栏排版）逐条呈现，行高重分配 27/87/74mm 且正文文字量超阈值的重内容页自动挂 print-dense 降密档，页眉只留真实产品入口与交接锚点。
14. 用户继续否决呈堂画布，最终明确需求为面向技术人员的培训手册与演示说明。页面改为标准技术文档三栏：左侧四阶段 14 幕目录，中间按「原理与结构 → 实操演示流程 → 场景案例与讲解 → 证据、验收与参考」组织正文，右侧同步当前步骤的讲解重点、交付、验收、误操作与拓扑入口。新增 MANUAL_PRINCIPLES 为 14 幕提供源码级原理说明；案例与代码默认展开，点击步骤只负责定位讲解，不再把页面做成数据大屏。图解不设独立素材展区，而是嵌入对应论述：原理说明后依次用结构图和架构图解释机制与系统位置，实操章以流程图引出逐步操作，案例章末用关系图收束 handoff DAG 与证据归属，最后进入证据验收；图由课程数据实时生成，形成「原理→图解→实操→案例→交接→验收」的连续叙事。打印 14 页 A4 教案同步纳入原理说明，重内容页采用更高打印密度但不删内容。
