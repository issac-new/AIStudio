1. **派发文案层（本仓）**：`custom/server/pipeline/pipeline-engine.ts` 新增导出常量 `DISPATCH_SAFETY`（同域多单并行三条款：独立 git worktree 隔离/互不等待/做完即止不展开），追加到持续测试与持续集成两条触发消息尾部——产品流水线的每次派发自带并行安全语义。测试 6/6 绿。
2. **计划层（simharness 15dce3e）**：pm-planning 技能新增「并行分配铁律 3a」——同域多单禁捆绑串行（多工位或单人多会话+worktree 隔离），真依赖用 rebase 对接不等开工，排期表须标并行度。源头治「拆分细≠分配匀」。

## 决策记录

1. 条款沉在引擎常量而非逐条消息内联：一处改全局生效，后续新增触发器复用同一常量（单一事实源）。
2. 极简单步令收口并入 DISPATCH_SAFETY 尾句（「只要求完成上述这一件事…做完即止」）而非单独模板：产品流水线消息天然单任务，缺的只是「禁展开」语义。
3. pm-planning 改技能不改引擎：分配策略属计划知识，产品引擎只管触发不管排班。
4. 本批不改 parallel-review 腿文案：其腿模板本就是逐腿单判据形态，无捆绑问题。
