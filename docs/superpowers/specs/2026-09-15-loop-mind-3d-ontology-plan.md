## 本体论要素清单（3D 场景应承载的实体与维度）

### 实体（一等公民）
1. **核心柱**（中心轴，贯穿各层）——思维主体
2. **任务/思想核**（球体）——kanban 任务
3. **运行尝试**（环绕任务的附属点）——task_runs
4. **（第二轮）运行内部 span**（agent/skill/tool/memory/审批）——观察台 TraceNode 九类，几何族区分（agent=多面体/tool=锥/skill=八面体/memory=环/审批=门）

### 关系（有向语义边）
1. 核心→任务（孕育）
2. 任务→运行（产生）
3. **（第二轮）任务→任务**（父子/跨会话委派，观察台 buildCrossSessionEdges 已有数据）
4. **（第二轮）重试弧**（失败尝试 N → 复活尝试 N+1，点线弧）

### 维度 → 通道映射（一维一通道，全部进图例；还旧账：半径不再一身二任）

| 数据维度 | 通道 | 依据 |
|---|---|---|
| 状态（running/awaiting/blocked/done/failed/idle/archived） | **色相**（全局 CSS 变量色板） | 最强分类通道，与扁平 UI 同语言 |
| 活跃 vs 沉降 | **高度层（Y）** | 现有语义，延伸为连续沉降（完成的任务缓慢下沉+结晶化） |
| 节点种类（agent/tool/skill/memory/approval） | **几何族** | 释放色相不单挑；形状是色相被占用时的正确分类通道 |
| token/成本体量 | **体积**（Stevens 幂律校正 ≈0.7，感知大小跟踪数值） | 静态总量→体积；活体燃烧率→粒子（二选一，不叠加） |
| 待介入（HITL 审批） | **专属动效：雷达脉冲环**（从节点扩圈，等待越久圈越密）+ 警示色相 | 必须跨房间召唤注意力；当前 awaiting 与 running 共用 pulse 是编码碰撞，必修 |
| 活跃数据流 | **沿边粒子流** | 运动=方向+活性；只在聚焦实体上开（守运动预算） |
| 失败历史 | **表面疤痕纹理**（持久，不消失） | 零运动、不与实时通道竞争 |
| 区内时序 | **距核心柱的径向距离**（新近核、旧远核） | 现有隐含语义，进图例显式化 |

### 时间（生长感来源）
- 萌芽入场（新任务沿核心柱边生长出来）
- 沉降连续化（完成的任务缓慢下沉一层并结晶）
- 记忆脉冲（进行中/待介入浮现→褪色）

## 层级缩放阶梯（语义缩放，非单纯拉近）

| 层级 | 范围 | 形态 | 交接 |
|---|---|---|---|
| L0 舰队 | 全部循环/看板 | 星座/城区（一循环一球，大小=活跃度） | 点击 → L1 |
| L1 单循环 | 一个思维图谱 | 当前层蛋糕+行星混合体（保留） | 语义缩放：标签只给活跃度 Top-N；远端运行坍缩为光点 |
| L2 单运行 | 一条运行 | **表征切换**：运行点展开为**时空螺旋**（span 珠串沿墙钟 Y 轴上升，stage 转换为螺旋圈） | 点击 span 珠 → L3 |
| L3 节点详情 | 一个 span | **2D 面板接管**：相机侧摆，屏幕右侧打开现有 RunTraceInspector/RunTraceNodeDetail 读全文 | 3D 只保留该 span + 紧邻上下文 |

## 3D 病理防线（ Munzner「无不正当 3D」护栏）

1. 遮挡：极角钳制（已有 phi≤0.55π）；待介入节点关深度测试（警报永不被遮）
2. 无意义纵深：XZ 散布的语义（径向=时序）进图例显式化，不让人瞎猜
3. 透视毁量级判断：精确数字只进标签与 2D 面板，不进大小
4. 标签杂乱：距离驱动标签 LOD（只给屏幕上最大的 N 个），悬停显示其余
5. 导航疲劳：约束轨道（不滚转）+ 书签视角（层切换按钮已是）+ 闲置自动回总览
6. 边 spaghetti：核心柱边束可见捆扎；非聚焦实体边淡出
7. 运动过载：全系统同时最多两种运动语义（流=运行中 + 脉冲环=待介入）
8. 状态突变：所有状态变化走分阶段过渡（任务 running→completed 应下沉而非瞬移）
9. 精灵性能：标签用共享图集；运行点 instanced mesh
10. 无障碍：键盘可达的实体列表作平行通道；prefers-reduced-motion 关粒子与相机自动运动；2D 降级路径（fallback-2d）保持功能对等
