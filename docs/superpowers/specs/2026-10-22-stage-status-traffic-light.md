# 左侧导航阶段状态点交通灯化（红黄绿）

> 2026-10-22 用户裁定：状态点用红黄绿（类似交通信号灯）比棕点/绿钩更直觉。

## 改动

- 判定正身 `useDailyStageProgress.dailyStageState` 新增第四态 `blocked`：阶段桶内
  出现 `blocked` 任务 → 红，优先于黄；blocked 只属④桶（running/blocked），①组织配置
  不由此推导（维持原特殊语义）。StageState 联合类型随之扩 `'blocked'`（消费方仅
  导航侧，已同步）。
- 呈现 `IaSideNavItem.vue`：绿✓=已完成（--ia-fresh，原样）、黄●=进行中（新
  token `--ia-warn`，不挪用 stale——stale 浅色 #7a5a06 观感偏棕正是本次痛点）、
  红●=有阻塞（--ia-fail）、灰○=未开始（原样）。aria-label 增「有阻塞/Blocked」。
- token 单一事实源 `ia2.scss` 状态色族增第六态 warn：浅 #a16207 / 深 #eab308
  （沿用该族 WCAG 2.2 AA 复核口径）。

## 不改

- 徽标（在办计数）口径与「徽标+状态点共存」布局不动（2026-10-22 徽标轮立法）。
- stale token 本体与其他使用方不动。

## 决策记录

| # | 决策 | 理由 | 否决的备选 | 可逆 |
|---|---|---|---|---|
| 1 | 状态点改红黄绿交通灯，红=新增 blocked 态 | 用户 2026-10-22 裁定「还是用红黄绿更好一些」；红在此有真实信息（④有阻塞任务） | 只换色不加红（否决：红无来源，三色缺一） | 是 |
| 2 | 黄用新 token --ia-warn 而非复用 --ia-stale | stale 浅色值观感为棕（用户原话「棕色的圈」），且 stale 语义=陈旧非进行中 | 改 stale 全局值（否决：波及 IDE 侧等其他使用方） | 是 |
| 3 | 红映射=阶段桶含 blocked 任务 | 交通灯红=有东西卡住需人看；blocked 状态已在看板九态中 | 红=未开始（否决：未开始不是告警） | 是 |
| 4 | 二轮去棕：黄/红改实心圆灯胆（--ia-warn-lamp #eab308 / --ia-fail-lamp #e03131，仅 :root 定义不随主题反转）；--ia-warn 文本 token 退役 | 用户二轮「不要棕色」——浅色 #a16207 仍观感偏棕；黄色作文本色在浅底无 WCAG ≥4.5:1 合格值（色彩学硬约束），实心灯胆是交通灯的正确形态 | 再调黄文本色值（否决：不存在合格值，仍会偏棕或过浅） | 是 |
