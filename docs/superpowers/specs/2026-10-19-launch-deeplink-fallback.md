# 旧启动页深链回退（2026-10-19）

## 背景

信任与归属纠偏删除了②需求阶段重复的「启动运行」页签，启动仍由 harness 执行。旧书签 `?tab=launch` 若按未知页签处理，会静默落到默认「需求与冻结」页，用户会误以为启动入口消失。

## 决策

旧 `?tab=launch` 在②阶段定向回退到「启动准备」，由该页如实说明启动/续跑在 harness 侧执行，并给出运行中心入口。其余未知页签仍按默认页回退。

## 决策记录

- D-1：只为②阶段保留 `launch → preflight` 定向回退，不把 `launch` 做成永久别名页签。
- D-2：不新增启动按钮，不改变一键启动仍属 Phase C 的冻结决策。
- D-3：守门测试覆盖旧深链，防止后续页签重组再次静默错位。
