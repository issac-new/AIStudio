## 四、修复归属

**产品侧（11 件）**：驾驶舱看板面板（白屏复现路径/计数口径统一/下拉截断/spinner 收敛）；治理中心文档查看器（markdown 表格·引用·加粗渲染/末行裁剪）；待裁决与审批收件箱（同对象去重/状态互斥/裸 hash 可读化/备注去重/风险档必填）；房间列表（同名合并或从属标注）；顶栏遥测计数链路；会话 tab（tooltip/自适应/序号）；治理工件列表高度自适应；群聊系统消息本地化或折叠+"等扶"勘误；版本 toast 可关闭+文案清理；卡片抽屉日期本地化+空字段占位；IDE"任务未投递"不应为可见常态。

**采集/生成器侧（6 件）**：快门时机守门（截图前断言目标组件非空：看板有卡/文档已选/成员面板展开/无 spinner/无 toast，空态重试或记缺陷）；拍前去噪（关 toast/收下拉/防底行裁切）；文件名-内容对齐校验（ui-02-profiles 实为看板、ui-26-report 错页）；同画面去重与"拍而未嵌"治理（文字引用必须配 img）；工件新鲜度（治理/审计/复盘证据图须取自本轮窗口工件，旧工件顶包即打回）；报告口径自洽（头部计数=实际嵌入数，R8 断言已接入 mx-report-audit）。
