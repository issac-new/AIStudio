# SwarmStudio 三中心重构·总设计定稿（全盘盘点后统一规划）

> **文档定位**：对账总表（redesign-reconciliation-ledger，A-G 七组 123 行）之上的**统一设计定稿**——此前 IA/盘点/镜头三档为过程稿，本档为最终形态单一事实源。冲突以本档+对账总表为准。
> **设计依据**：全盘盘点三层收口（路由 21+岛屿→board 13 签→设置 E/F/G 三层 72 项）× 三件产品定位（驾驶舱+推演引擎+研发治理）× 治理六域（流程/人员/资产/权限/成本/功能）× 四角色镜头（产品/研发/测试/治理）× 一人对账（123 行零双家零孤儿）。

## 一、总架构：三中心 + 岛屿 + 三设置页 + 角色镜头

```
顶栏：[工作台] [推演中心] [治理中心] ｜岛屿：IDE·BPA·本体·评测·技能治理｜ [设置] [镜头切换器]
─────────────────────────────────────────────────────
角色镜头层（旅程条+四维摘要带）盖在三中心之上，随登录身份切换
三设置页（工作台·设置/治理·系统设置/推演设置）从顶栏 [设置] 进入
```

## 二、工作台（驾驶舱——人的当日工作面）

**组成**：三栏壳（A1）＋board 3 签（B1 看板·我的卡默认/B2 任务协同/B3 协作与知识·含交接）＋inbox（A11+D5 审批+清偿门）＋沟通四路由（A14-17+历史+agent）＋IDE 生产位（A18，岛屿深链）。

**首页「我的驾驶位」**（四角色共入口，镜头决定内容）：我的卡＋待我出手的人形待办卡＋我的会话三块。

## 三、推演中心（引擎——一轮推演的指挥与观测）

**组成**（6 签）：轮次总览（D1 姿态横幅+六闸全名+净额双行卡+容量摘要行）·监督面板（D2 观察窗流+研判/判词时间线+journal）·运行观测（B6+D4 派发器健康卡+休眠卡）·证据库（D3 帧/台账/事件/journal/案例 A6，锚点一键反查）·交付健康（B5 宽限窗语义）·需求追溯（B4 provenance）。壳=runs 升格（A13）；场景编排（A8/D9）为其执行器；推演设置页（E28）挂此。

## 四、治理中心（研发治理——六域管理+关卡问责）

**7 签**：关卡与流程（C5 六闸+D6 orgloop+流程定义态）·组织与权限（A3 人员编制+RACI+账号）·资产与能力（B7 应用资产/技能/功能开关）·清偿门（D5 审批流）·问题单对账（C4）·审计与变更（B8）·文档评审（B9）·度量体检（B10-13+C3 五卡+成本卡）。

> 注：治理 8 区（7 签+系统设置页）按六域对账：流程=关卡与流程签+流程设置区；人员=组织与权限签；资产=资产与能力签；权限=组织与权限签+门控语义（G26）；成本=度量体检成本卡+模型/用量设置区；功能=资产与能力签+功能开关区。

## 六、角色镜头层（盖在三中心上）

旅程条（四角色站点配置表）＋镜头切换器（一人四镜头）＋四维摘要带＋14 个人工介入待办卡（带人形图标、批准/打回双钮、全留痕）＋四张角色首页（产品「我的需求」AC 进度环/研发「我的卡」抽屉四页/测试「测试台」缺陷泳道/治理「驾驶位」六域状态）。G1-G6 全名标注（需求冻结/架构评审/编码门禁/独立测试/发布准出/复盘）。

## 七、六条全局 UI 规范

①三中心一级导航+单层页签（无二级）②状态色系（fresh 绿/stale 琥珀/fail 红/pass 深绿/compensated 紫）③姿态横幅常驻推演中心④锚点直达（任何数字/判词/帧→右抽屉证据原文）⑤中文说人话+术语全名首现⑥密度三级（仪表一行卡→表→抽屉）。
