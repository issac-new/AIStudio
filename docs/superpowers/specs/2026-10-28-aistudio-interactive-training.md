# AIStudio 交互式培训手册设计规格

## 变更

新增独立 HTML 培训页和本地启动器。手册分为设计、实现、部署、使用四部分，每部分 3 幕，共 12 幕。每幕使用对应模块的独立 SVG 拓扑演示工作流转。页面上方展示拓扑，下方说明目标、操作和完成判据，并支持自动播放、暂停、回放和键盘操作。

启动方式包括 `npm run training`、macOS 双击 `.command` 和 Windows 双击 `.bat`。启动器仅监听 `127.0.0.1`，自动选择空闲端口并打开浏览器。基础培训不依赖 AIStudio 后端、模型、Matrix 或真实业务数据。

## 决策记录

1. 使用独立 HTML、CSS 和 JavaScript，不把培训功能植入产品前端。培训页可离线启动，避免环境依赖影响基础教学。
2. 所有产品界面均明确标注为培训模拟。页面不连接生产服务，不读取真实账号、任务或审批数据。
3. 四个模块使用独立拓扑，不只切换高亮。设计模块展示五层系统协作与 15 步协作流，实现模块展示 ready、running、blocked、review、done 的状态分支。部署模块按 gateway、kanban、worker、ACP、Ycode 的实际关系展示，使用模块区分日常检索、评测修复和治理改进。Matrix 标为可选协作分支，kanban 标为任务真值，评测只在新证据满足同卷同版、通过且无红线时关闭。
4. 每一步同时给出拓扑操作位置和完成判据。自动播放与手动跟练共用同一份 12 幕课程数据，避免两套流程漂移。
5. 启动器只放行培训 HTML 和文字手册。默认使用随机空闲端口。`--no-open` 与 `--port` 供自动化验证使用。
6. 保留现有文字手册作为详细参考。交互页负责流程演示，文字手册负责完整约束和故障处理。
7. 页面尊重 `prefers-reduced-motion`。减少动态效果时直接呈现终态，且不自动播放。
8. 当前激活路径只渲染 `renderTopology()` 生成的 inline SVG。每幕高亮当前节点与流转，“显示全部流转”可查看本模块完整拓扑。减少动态效果时不生成流动动画，也不自动播放。Pretext 是可选增强，独立离线页未打包 `prepare/layout` 时直接使用浏览器自然换行，不在每次切幕时记录回退警告。
9. 自动播放、目录跳转和手动跟练共用同一个场景索引。切幕后立即重绘拓扑和说明区，播放状态、进度和完成记录保持同步。
10. 页面采用无遮罩横屏布局。常驻课程栏改为顶部四部分短导航和目录弹窗。上方画布只显示拓扑，下方用横向信息带呈现说明，当前操作和流转切换放在页脚。取消右侧悬浮面板、圈选光圈与引导线。
11. 仅面向 PC 横屏使用。拓扑采用固定视口和独立文字层级，不用整页缩放代替布局。移动端不纳入本次交付与验收范围。
12. 视觉采用浅色图纸风。白底节点与浅灰层级承载内容，深绿路径突出运行方向，标签保留留白。主题变化不改变事实结构与课程数据。
13. 文字手册按当前整体包 `1.0.8-overlay` 核实。评测页补全八页签和“技能评估”操作契约：评估 spec 第 19 节，S0/S1 分层判定，`CONDITIONAL` 不算通过；同时写清四模块发布边界和每节点一个 gateway 的默认部署关系。交互版在使用模块补充同一判定提示，不为新页签虚构第五条业务流。

## 验证

- 启动器与课程契约：`npx vitest run custom/__tests__/interactive-training-manual.test.ts`，10 项通过、0 项失败。覆盖四部分 12 幕、15 步协作流、四套不同拓扑、当前版本、Eval 八页签、技能评估判定、启动入口、路径限制和 Pretext 缺席保护。
- 启动器实测：`node scripts/start-training-manual.mjs --help` 正常；`npm run training -- --no-open --port 8877` 在 `127.0.0.1:8877` 返回 200，进程 cwd 已核验为本 worktree。
- 文档检查：文字手册本地链接无断链；整体版本与 `package.json` 的 `1.0.8-overlay` 一致。
- PC 浏览器走查：Chromium 在 1280×720 与 1600×900 横屏视口均无横向溢出。设计、实现、部署、使用分别渲染 9、10、15、12 个拓扑节点，不是同图换高亮。
- 交互走查：课程目录含 12 幕，跳转第 11 幕后正确显示技能评估提示；使用模块“显示全部流转”为 10/10；播放按钮在“播放/暂停”间切换且 `aria-pressed` 同步。
- 控制台：走查首次发现 `prepare is not defined`。加入可选库缺席保护后清空控制台并重载，复跑四模块、目录和完整流转，结果为 `(no console errors)`。
- 截图证据：`.gstack/browse-reports/2026-11-02-training-update/screenshots/` 为本地运行态，不入库。

未覆盖：未使用真实业务账号重新执行完整培训流程，未验证 Matrix、模型、worker 和治理仓的外部依赖；macOS 与 Windows 双击入口未分别在对应桌面环境实机双击；手机端不在本次验收范围。
