# AIStudio 全局检索合并至顶部栏弹窗规格

- 日期：2026-10-27
- 状态：实施中
- 分支：`feat/global-search-consolidation`
- 关联：`2026-10-18-ia-leftnav-stage-tabs.md` 第九节

本文主旨是把重复检索收为一个顶部入口和一个完整弹窗，并保住旧链接与既有能力。读者是后续开发与审查者。读完应能按本文列出的行为逐项验收。

## 背景

当前同屏存在左侧「检索」和顶部搜索框。左侧页搜索五类对象，并提供类型计数与组合筛选。顶部 Spotlight 重复搜索会话、任务和运行，另提供命令与键盘导航。顶部还会打开独立检索页或上游会话全文弹窗，形成三层动线。

合并不能只删左侧按钮。文档、人员、筛选、命令、键盘操作和旧深链都必须有明确去向。上游会话全文搜索只覆盖本地会话与消息，不能替代五类对象检索。

## 变更

### 1. 顶部唯一入口

- 删除左侧常用组的「检索」。常用组保留流程总览、工作台、看板、审批收件箱。
- 顶部输入框和 `Cmd/Ctrl+K` 保留。IDE 路由继续让位给 IDE 命令面板。
- 顶部与弹窗输入共用 `cockpit.searchQuery`。正常打开弹窗不改变当前路由。

### 2. 一个完整检索弹窗

- 新增 `GlobalSearchDialog` 与共享弹窗状态。退役 `SpotlightPanel.vue` 和独立页 `SearchView.vue`。
- 弹窗提供会话与房间、任务、运行、治理文档、人员五类结果。
- 保留类型计数及工作区、状态、负责人、时间筛选。
- 命令组合入同一弹窗。上下键、Enter、Escape、遮罩关闭和焦点归还使用同一套交互。
- 任务结果统一跳看板深链，由看板打开任务详情并复用 sim 任务处理。
- 文档索引只在弹窗首次打开时请求。请求失败显示真实错误。
- 「会话消息全文」保留为高级入口，继续调用现有 `SessionSearchModal`。
- 本次不改上游组件、服务端接口或搜索分页契约。

### 3. 旧链接与壳层兼容

- 保留 `ia2.search` 路由名，将 `/app/search` 改为显式重定向。
- 重定向目标为流程总览，并以 `search=1` 唤起同一弹窗。
- 旧链接的 `q/type/ws/status/assignee/time` 和 `standalone` 原样保留。
- 关闭深链弹窗时只清理检索拥有的参数。
- 弹窗挂在共享顶区，覆盖日常、IDE 和收编页。独立窗口由 `IaShell` 增加同一宿主。
- 404 出口和历史最近轨迹继续打开弹窗。弹窗参数不重复写入最近轨迹。

### 4. 同步范围

- 更新 Vitest、浏览器走查脚本、路由清单与 `ia-search` 推演采集。
- 更新整合设计正本、数字总账、USAGE 和全流程方案。
- 本次为 A 类 `custom/`、`scripts/`、`simharness/` 与文档变更。
- 本次不新增依赖，不改 `vendor/` 基线。
