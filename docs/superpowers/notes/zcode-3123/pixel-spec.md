## 六、改造清单（/ide → 规格）

1. IdeTaskSidebar：宽 264→270；过滤行加「# 分组 / 📁 项目」chip 形态；底部加账号行；任务项行高 34、时间右对齐 11px；删除现有 footer 单图标布局改账号行。
2. IdeChatPane：标题栏重排（标题+⋯+分支 chip+分享+？+⛶），下加运行状态条；输入框重绘（+ / 权限 chip / 模型 chip / ↑圆钮 28px accent 圆角 12 框）。
3. IdeSidePane：页签形态改 ZCode 胶囊+×（现有 tab 条已近，补 + 号与宽度 480 默认、800 上限）。
4. 色彩令牌：--ide-bg-side #1a1c20 / --ide-bg-chat #202226 / --ide-bg-card #23262b / --ide-border #2a2d33 / --ide-accent #5b9cf6 注入 IdeShell 局部作用域（不动全局主题）。
5. 保留增强（高于 ZCode 项）：状态栏、终端工具启动器、诊断 popover、模型失效条。

## 七、底层约束（用户裁定）

- 运行时 = **codex 唯一默认**（store/ide.ts DEFAULT_IDE_AGENT='codex'；并行会话改 'ln' 的漂移须修回）；agent 选择器收敛为 codex 单项展示，不做多运行时切换 UI。
- 代码底座 = 上游 codex 集成层（MessageList/ChatInput 家族复用不动其协议），二开仅落 overlay custom + patch。
