# 自托管知识库（RAG）选型方法论与裁决记录

> 场景：单机（Apple Silicon / 32GB / Docker）、中文语料为主、个人 agent 集群无头调用（API/MCP-first）、数据卷外置盘。2026-11 完成选型，**终选 WeKnora**（v0.9.0，Apache-2.0），RAGFlow（v1.0.0）列观察名单。

## 三重验证法（可复用）

纸面对比只能初筛，选型落锤必须三步走：

1. **黑盒 POC（同口径实测）**：同一组混合语料（md+pdf+长文），双平台盲测三类检索（英文字面 / 中文语义换词 / PDF 内容）；内存用 cgroup `memory.peak` 逐容器取生命周期峰值（官方宣称数字不作数，实测可差一个数量级）；问答验收=答案带真实引用锚点。
2. **全市场扫描**：候选分三层（基座引擎 / 平台 / 工具框架），逐个过六关（检索架构、解析深度、中文、资源、许可、维护健康度）；**死缓项目一票否决**（停更/归档/未修安全洞）。
3. **源码白盒**：锁定 POC 同版本 tag 读源码——重点实证检索数学（召回路数/融合算法常量）、安全基线（token 存储/SSRF）、以及**证伪纸面宣传**（本轮证伪一条「三路 RRF」第三方误传、纠正一条自家 POC 推断）。

## 关键实测结论（摘要）

| 维度 | WeKnora v0.9.0 | RAGFlow v1.0.0 |
|---|---|---|
| 检索盲测 | 3/3 命中 | 1/3（词法腿融合权重源码写死 0.001，混合名存实亡）|
| 内存峰值（全流程）| ~1.15GB（单 PG 一库三用：业务+pgvector+BM25）| ~5.2GB（ES 独占 2.6GB）|
| 检索数学（源码）| 两路加权 RRF(k=60)+复合重排(0.6/0.3/0.1)+MMR | 无 RRF；ColBERT Go 版未实现 |
| 安全基线（源码）| 敏感字段 AES-256 | api_token/模型 key 明文存储 |
| LLM/嵌入 | 任意 OpenAI 兼容端点 + 本地 Ollama 嵌入 | 同 |

## 避坑提示（跨平台通用）

- 嵌入模型维度入库后不可换；换嵌入=重建索引。
- 容器连宿主服务用 `host.docker.internal` 前先查平台 SSRF 白名单机制。
- macOS 对外置卷有 TCC 权限回收前科：关键脚本勿只存外置盘。
- 「开箱默认」与「调优上限」是两个口径，评测报告必须写明用的哪个。

完整证据链（五份报告，含 120+ file:line 源码锚点）见本目录 `selection-evidence.md` 与 `weknora-deployment-runbook.md`。
